## 新投稿 (6)

<h3 id="1">[1] Ankhdjet: An Open-Source Compiler for Mask-Programmed Ternary Compute-in-ROM on an Open PDK</h3>
- **arXiv**: [2608.26206](https://arxiv.org/abs/2608.26206)
- **Authors**: Mohnish Pai
- **Subjects**: cs.AR; cs.ET
- **Tags**: Compute-in-ROM, Ternary Quantization, LLM Inference
- **Summary**: 该论文解决大规模语言模型推理中权重移动开销大以及硬连线权重芯片无法用开源工具复现的问题。作者提出Ankhdjet，一个开源编译器，将HuggingFace三元检查点（如BitNet b1.58）转换为开放SKY130 PDK上固定计算-ROM宏的掩膜程序，并通过完整开源工具链验证。结果显示该编译器是首个全开源流程的权重到掩膜计算-ROM编译器，数字读出方案面积仅为模拟读出八分之一，仿真读出能量为0.98-1.73 pJ/权重。

<h3 id="2">[2] MeshReduce-U: Compiler-Guided Communication Reduction for Irregular Neural Reductions on Mesh NoCs</h3>
- **arXiv**: [2608.26220](https://arxiv.org/abs/2608.26220)
- **Authors**: Amirreza Khorasanian
- **Subjects**: cs.AR; cs.DC
- **Tags**: Network-on-Chip, Compiler Optimization, AI Accelerator
- **Summary**: 论文针对网格NoC上不规则的神经规约通信导致流量大和延迟高的问题，提出MeshReduce-U，一个编译器引导的通信缩减与路由框架，通过合并共置源、形成局部聚合岛、阻塞兼容扇入信道等方式在路由前消除通信。在20个工作负载上，与基线相比平均延迟、总链路使用率(TLU)和融合链路使用率分别降低40.3%、56.0%和48.7%。

<h3 id="3">[3] Beyond Edge Cuts: Activity-Weighted Multicast Hypergraph Mapping for Spiking Neural Networks on Mesh NoCs</h3>
- **arXiv**: [2608.26223](https://arxiv.org/abs/2608.26223)
- **Authors**: Amirreza Khorasanian
- **Subjects**: cs.AR; cs.NE
- **Tags**: Spiking Neural Network, Neuromorphic Computing, Network-on-Chip
- **Summary**: 论文认为传统图划分和成对放置成本不匹配SNN在多核神经形态平台上的多播通信事件，提出M-HySMap，一种活动加权多播超图映射框架，通过增量增益评估和局部性优化降低路由跳数。在115个任务上，路由多播跳数比Activity+QAP降低10.6-19.6%，比Edge+QAP降低19.7-41.1%，增量更新加速4.7-12.7倍。

<h3 id="4">[4] Redwood: A Frontier AI Accelerator Designed, Verified, and Deployed from Scratch in 2 Weeks by AI</h3>
- **arXiv**: [2608.26418](https://arxiv.org/abs/2608.26418)
- **Authors**: Architect Labs
- **Subjects**: cs.AR; cs.AI
- **Tags**: AI Accelerator, Hardware-Software Co-design, LLM for EDA
- **Summary**: 论文指出硬件设计周期与AI工作负载演进速度不匹配的矛盾，提出一个端到端AI系统，将软件到硅片栈折叠为单一优化循环，自主完成硬件和软件协同设计与验证。其演示Redwood加速器在两周内从高层规格生成性能模型、RTL、UVM环境、形式验证、固件和内核；在Samsung 8nm工艺上相比Jetson Orin Nano实现3.4倍性能功耗比提升。

<h3 id="5">[5] HOLMES: In-Context Failure-Center Localization for High-Dimensional Yield Estimation</h3>

- **Venue**: ICCAD 2026

<h3 id="8">[8] SILK: Closing the Time-of-Check-to-Time-of-Use Gap in RoT-Protected AI Systems</h3>
- **arXiv**: [2608.26402](https://arxiv.org/abs/2608.26402) (cross-listed)
- **Authors**: Ruichen Qi, Xinting Jiang, Ema Dimitrova, Junyi Luo, Quan Cheng, Mehdi Saligane
- **Subjects**: cs.CR; cs.AR
- **Tags**: AI Security, Hardware Security, Trusted Execution Environment
- **Summary**: 论文指出根信任在加载时验证DNN模型，但权重在传输路径上可能被篡改，形成TOCTOU完整性缺口。作者提出SILK，一种流式内联轻量密钥机制，在最终计算边界验证权重流，利用量化权重LSB作为密钥完整性位并链式依赖。实验表明SILK能检测所有流修改攻击，INT8下CNN准确率损失不超过0.76个百分点，LLM困惑度损失不超过0.17。

<h3 id="10">[10] Characterizing CPU-Induced Slowdowns in Multi-GPU LLM Inference</h3>
- **arXiv**: [2603.22774](https://arxiv.org/abs/2603.22774) (replaced)
- **Authors**: Euijun Chung, Yuxiao Jia, Aaron Jezghani, Hyesoon Kim
- **Subjects**: cs.AR; cs.DC
- **Tags**: LLM Inference, GPU Computing, Distributed Inference
- **Venue**: IISWC 2026
- **Summary**: 论文揭示多GPU LLM推理性能下降往往源于CPU无法及时维持GPU忙碌，而非GPU饱和。在有限的CPU分配下，出现内核启动延迟、通信停滞和令牌化延迟，导致GPU利用率严重不足。实验表明增加CPU核可在不增加GPU的情况下将TTFT延迟降低1.47-7.11倍。

<h3 id="11">[11] HARP: Hadamard-Domain Write-and-Verify for Noise-Robust RRAM Programming</h3>
- **arXiv**: [2604.12420](https://arxiv.org/abs/2604.12420) (replaced)
- **Authors**: Ilhuan Choi, Jiwon Yoo, Yoona Lee, Yewon Jeong, Jason Jaesung Lee, Woo-Seok Choi
- **Subjects**: cs.AR
- **Tags**: ReRAM, Compute-in-Memory, Analog Computing
- **Venue**: ICCAD 2026
- **Summary**: 论文解决RRAM多级权重编程中写-验证在低信噪比下验证读取可靠性受限的问题，提出Hadamard域编码并行验证(HD-PV)和基于ADC能量降低的HARP。HD-PV用N个正交Hadamard模式替代one-hot验证读取，解码将噪声方差减小N倍。在CIFAR-10严重读取噪声下，传统WV损失超20%准确率，而HD-PV和HARP仅损失0.6%和1%，并实现6.2倍和9.5倍能效提升。

<h3 id="12">[12] Predictive Software Scheduling as an Early-Warning Hint Layer for Optical Engine Thermal Drift in Heterogeneous SoIC Packaging</h3>
- **arXiv**: [2605.18612](https://arxiv.org/abs/2605.18612) (replaced)
- **Authors**: Chi Fei Chung
- **Subjects**: cs.AR
- **Tags**: Co-Packaged Optics, Thermal Management, Scheduling
- **Summary**: 论文针对共封装光学集成中微环谐振器对温度敏感导致热光耦合问题，提出预测性软件调度作为预警提示层，通过软件调度缓解光学引擎热漂移导致的BER退化。文章指出±1.7nm谐振波长偏差即可导致可测量的误码率退化。
