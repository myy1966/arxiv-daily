## 新投稿 (6)

<h3 id="1">[1] ACALSim: A Scalable Parallel Simulation Framework for High-Performance System Design Space Exploration</h3>
- **arXiv**: [2605.22936](https://arxiv.org/abs/2605.22936)
- **Authors**: Wei-Fen Lin, Jen-Chien Chang, Yen-Po Chen, Zi-Yi Tai, Yu-Cheng Chang, Chia-Pao Chiang, Yu-Yang Lee, Yu-Jie Wan
- **Subjects**: cs.AR; cs.PF
- **Tags**: Hardware Simulation, High Performance Computing, GPU Computing
- **Summary**: 本文提出了ACALSim，一个可扩展的并行仿真框架，用于高性能计算系统的设计空间探索。该框架通过可插拔的线程管理架构、事件驱动执行和共享内存数据模型，相比SST实现了超过14倍的加速和41%的内存占用降低。

<h3 id="2">[2] MASQ: Accelerating Masked Diffusion via Stage-Wise Multi-Precision Quantization</h3>
- **arXiv**: [2605.23226](https://arxiv.org/abs/2605.23226)
- **Authors**: Seeyeon Kim, Jaehun Lee, Sungyeob Yoo, Joo-Young Kim
- **Subjects**: cs.AR
- **Tags**: Diffusion Model, Hardware Acceleration, Quantization
- **Summary**: 本文提出MASQ，一种面向掩码扩散的软硬件协同设计加速器，采用阶段式多精度量化策略动态反映空间和语义重要性。该方案在保持图像质量的同时，相比A100和Orin NX分别实现了最高16.06倍和5.39倍的加速。

<h3 id="3">[3] NASiC: 3D NAND-based CAM-Selected Multibit CIM Architecture for Efficient On-Device Mixture-of-Experts LLM Inference</h3>
- **arXiv**: [2605.23294](https://arxiv.org/abs/2605.23294)
- **Authors**: Weikai Xu, Meng Li, Shuzhang Zhong, Tianyang Luo, Dongxue Zhao, Ling Liang, Zongwei Wang, Qianqian Huang, Yimao Cai, Ru Huang
- **Subjects**: cs.AR
- **Tags**: Compute-in-Memory, Mixture-of-Experts, LLM Inference
- **Venue**: DAC 2026
- **Summary**: 本文提出NASiC，一种基于3D NAND的CAM选择型存内计算架构，专为MoE LLM推理设计。该架构将动态专家选择与激活专家计算融合到单个计算周期中，相比现有设计实现了4-114.8倍的性能提升和3.9-70倍的能效提升。

<h3 id="4">[4] DAE4HLS: Exposing Memory-Level Parallelism for High-Level Synthesis using Explicit Decoupling</h3>
- **arXiv**: [2605.23549](https://arxiv.org/abs/2605.23549)
- **Authors**: David Metz, Magnus Själander
- **Subjects**: cs.AR
- **Tags**: HLS, Memory Architecture
- **Summary**: 本文提出DAE4HLS，一种用于高层次综合的解耦访问执行范式，通过显式解耦请求和响应来释放内存级并行性。该方法应用于AMD Vitis HLS工具链，实现了10-79倍的总体加速。

<h3 id="5">[5] To Overlay or to Customize? Revisiting Architectural Choices in Heterogeneous Systems</h3>
- **arXiv**: [2605.23630](https://arxiv.org/abs/2605.23630)
- **Authors**: Xingzhen Chen, Shixin Ji, Zheng Dong, Peipei Zhou
- **Subjects**: cs.AR
- **Tags**: Autonomous Driving, DNN Deployment, Hardware Architecture
- **Summary**: 本文从部署角度系统研究了异构系统中覆盖层架构与定制化加速架构之间的权衡，以自动驾驶场景为例。分析表明覆盖层架构更适合频繁模型切换场景，而定制化架构在效率需求高的工作负载中更具优势。

<h3 id="6">[6] DORA: Dataflow-Instruction Orchestration Architecture for DNN Acceleration</h3>
- **arXiv**: [2605.23833](https://arxiv.org/abs/2605.23833)
- **Authors**: Xingzhen Chen, Zhuoping Yang, Jinming Zhuang, Shixin Ji, Sarah Schultz, Zheng Dong, Weisong Shi, Peipei Zhou
- **Subjects**: cs.AR
- **Tags**: Hardware Acceleration, DNN Deployment, Hardware Architecture
- **Code**: [code](https://github.com/arc-research-lab/DORA.git)
- **Summary**: 本文提出DORA，一种基于指令的覆盖层架构，通过显式描述数据流实现对DNN加速的细粒度控制。该框架包含两阶段设计空间探索的编译流程，在AMD Versal VCK190平台上实现了相比现有加速器最高5倍的吞吐量提升。

<h3 id="7">[7] UniSpike: Accelerating Spiking Neural Networks on Neuromorphic Systems via Eliminating Address Redundancy</h3>
- **arXiv**: [2605.23796](https://arxiv.org/abs/2605.23796) (cross-listed)
- **Authors**: Qinghui Xing, Zhuo Chen, Xin Du, Ouwen Jin, Ming Zhang, Pan Lv, Ying Li, Shuiguang Deng, Gang Pan
- **Subjects**: cs.NE; cs.AR
- **Tags**: Spiking Neural Network, Neuromorphic Computing, Hardware Acceleration
- **Venue**: DAC 2026
- **Summary**: 本文提出UniSpike，一种软硬件协同设计方案，通过消除地址冗余来加速神经形态系统上的脉冲神经网络。该方法将发往同一核心的脉冲聚合为紧凑数据包，平均减少1.93倍流量，实现1.77倍加速和1.50倍能效提升。

- **Tags**: Compute-in-Memory, LLM Inference, Compiler Optimization
- **Code**: [code](https://github.com/SPIN-Research-Group/DCC)

<h3 id="9">[9] Bridging the Last Mile of Circuit Design: PostEDA-Bench, a Hierarchical Benchmark for PPA Convergence and DRC Fixing</h3>
- **arXiv**: [2605.06936](https://arxiv.org/abs/2605.06936) (replaced)
- **Authors**: Pengju Liu, Nuo Xu, Jinwei Tang, Yu Cao, Caiwen Ding
- **Subjects**: cs.AR; cs.AI; cs.MA
- **Tags**: EDA, LLM Agent, Benchmark
- **Summary**: 本文介绍PostEDA-Bench，一个用于EDA最后阶段任务的层次化基准测试，涵盖DRC修复和PPA收敛。实验表明LLM智能体在合成DRC任务上表现尚可，但在实际DRC推理和多目标PPA任务上性能急剧下降，最佳成功率仅为36.66%和20%。
