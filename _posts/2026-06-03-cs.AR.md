<h3 id="1">[1] Heterogeneous Mapping for Analog In-Memory Computing Accelerators: A Unified Workflow</h3>
- **arXiv**: [2606.02672](https://arxiv.org/abs/2606.02672)
- **Authors**: Corey Lammie
- **Subjects**: cs.AR; cs.ET
- **Tags**: Analog In-Memory Computing, LLM Inference
- **Venue**: IEEE Computer Architecture Letters
- **Summary**: 该论文针对模拟内存计算加速器中数字与模拟资源的DNN工作负载映射问题，提出了一个统一的四阶段工作流。通过将前两个阶段应用于GPT-2，首次得到解码器-only Transformer的AIMC精度敏感性分布图，发现早期块和输出投影对精度影响最大。

<h3 id="2">[2] CRAM-ER: Error-Resilient Spintronic Computational Random Access Memory for Scalable In-Memory Computation</h3>
- **arXiv**: [2606.02781](https://arxiv.org/abs/2606.02781)
- **Authors**: Sohan Salahuddin Mugdho, Md. Shahedul Hasan, Brahmdutta Dixit, Yang Lv, Jian-Ping Wang, Cheng Wang
- **Subjects**: cs.AR; cs.AI; cs.ET
- **Tags**: Compute-in-Memory, Fault Tolerance, Hardware-Software Co-design
- **Summary**: 该论文针对基于MRAM的计算随机存储器（CRAM）在加速DNN时的可靠性和吞吐量问题，提出CRAM-ER架构，采用混合自旋电子CRAM与CMOS加法器树，并配合误差感知微调。评估显示在几乎不损失精度下，CRAM延迟降低两个数量级，能效优于CPU/GPU。
