<h3 id="1">[1] Accelerating CPU Speculative Decoding via Unified Graph Execution and Transactional KV Isolation</h3>
- **arXiv**: [2610.28671](https://arxiv.org/abs/2610.28671)
- **Authors**: Zhangdie Yuan
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Speculative Decoding
- **Summary**: 该论文针对在CPU上部署投机解码时存在的上下文切换延迟和KV缓存回滚内存分配开销等系统瓶颈，提出了SubTernary执行框架，通过统一图缓存和事务性KV缓存隔离，将两个模型编译到单一内存区域并路由投机令牌到静态暂存区，实现零拷贝指针重置。实验表明，系统运行时贡献了35.0%的吞吐量提升，三元SIMD内核额外贡献6.0%，相比投机解码实现1.35倍加速，相比自回归解码实现3.99倍加速，并保持O(1)回滚延迟。

- **Tags**: LLM for EDA, Code Generation

- **Subjects**: cs.AR; cs.DC; cs.PF
- **Tags**: Attention Mechanism, Hardware Acceleration
- **Summary**: 该论文针对FlashAttention在长向量处理器上移植效率低的问题，将PyTorch CPU FlashAttention内核移植到RISC-V CPU，发现仅达到峰值浮点吞吐的16.2%，并提出两种优化：转置分数块和运行输出使查询沿连续轴排列，以及将多项式系数移入标量寄存器消除溢出。在真实芯片上，两种优化结合将内核周期减少1.84至2.08倍，浮点利用率从16.2%提升至29.7%，FPGA实现获得2.71倍加速。

<h3 id="13">[13] A parity obstruction to degree-optimal syndrome extraction in bivariate bicycle codes</h3>

- **Authors**: Guangyi Li, Yu Gan, Zeguan Wu, Xueyue Zhang, Zheshen Zhang, Junyu Liu
- **Subjects**: cs.AR
- **Tags**: Quantum Error Correction, Formal Methods
- **Summary**: CSS码的综合征提取深度至少为Tanner图度数Δ，但正确性会引入奇偶约束，此前仅有针对具体实例的不可行性结果。本文证明三个一般性障碍，并证明对于所有权重为三、校验至多重叠两个量子比特的双块群代数码，不存在深度为六的正确单轮电路，最小深度为七，从而说明Bravyi等人的七层循环对其七个双变量自行车码是最优的。这是首个解析的、族级的不可能性结果，并附带DRAT证书。
