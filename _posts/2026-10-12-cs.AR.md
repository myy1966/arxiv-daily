<h3 id="1">[1] VortexSynth: Profile-guided benchmark reconstruction for GPU architecture research</h3>
- **arXiv**: [2610.12661](https://arxiv.org/abs/2610.12661)
- **Authors**: Huanzhi Pu, Chulhyung Park, Chihyo Ahn, Ramyad Hadidi, Hyesoon Kim
- **Subjects**: cs.AR; cs.PL
- **Tags**: GPU Computing, Benchmark
- **Summary**: GPU架构研究常因厂商定制工作负载闭源或依赖目标架构不支持的编程模型，而缺乏可运行的基准测试。本文提出VortexSynth，通过性能剖析选取热点内核、在目标语言中合成实现、验证输出等价性，并利用代理实现测量性能剖析差异，将差异签名交给智能体迭代优化。在开源ISA的Vortex GPGPU上以机器人应用为域进行评估，所有活跃内核对均通过输出等价性检查，案例研究表明迭代优化可缩小性能剖析距离。

<h3 id="2">[2] CacheFlex: Direct Software-Managed Access to Higher-Level Cache for Scalable Vector Support</h3>
- **arXiv**: [2610.12940](https://arxiv.org/abs/2610.12940)
- **Authors**: Jingqun Zhang, Maohua Nie, Jiayi Wang, Weihang Li, Rishi Sappidi, Shwet Chitnis, Ang Li
- **Subjects**: cs.AR
- **Tags**: Hardware-Software Co-design, Hardware Architecture
- **Venue**: MICRO 2026
- **Summary**: 更宽的向量/SIMD通道提升了计算吞吐，但L1数据缓存容量受流水线耦合与延迟约束，而私有L2虽容量大却无法被软件直接访问，成为性能瓶颈。本文提出CacheFlex，一种ISA与微架构协同设计，允许运行时将部分L2转换为软件管理的暂存存储器，并支持跨域内存一致性与操作系统上下文切换，面积开销仅为L2的2.02%。在gem5中基于Armv8-A SVE原型评估，向量长度从512位扩展到2048位时，内核级几何平均加速从1.12倍提升至1.44倍，内存子系统能耗降低26%至40%；结合FlashAttention的完整Transformer层最高加速1.78倍、节能45%。

<h3 id="3">[3] TPCS: A Cycle-Level Simulation Paradigm with Native Execution Semantics for RTL Modeling and Generation</h3>
- **arXiv**: [2610.13067](https://arxiv.org/abs/2610.13067)
- **Authors**: Chengzhen Meng, Xiaoyu Li, Chen Bai, Zhenyu Zhang, Hongjun Dai
- **Subjects**: cs.AR
- **Tags**: Hardware Simulation, EDA
- **Summary**: 领域专用架构与微架构设计日益多样，但现有评估方法面临速度与保真度的根本权衡：高层模拟器快但精度低，RTL工具准确但仿真开销大，限制了RTL前的高效探索。本文提出事务剪枝周期仿真（TPCS），将组合逻辑组织为基于事务的函数调用，利用宿主CPU控制流自然剪枝非活跃逻辑，无需显式事件调度或信号追踪，并支持自动生成可综合RTL。TPCS在SMP系统上比并行Verilator快36至42倍，在加速器上比单线程Verilator快3.4至7.2倍，波形周期级一致，生成RTL的时钟周期与标准单元面积相对手工实现变化在-4.7%至+4.0%之间。

- **Venue**: IEEE CSCN 2025
- **Summary**: 面向全自动驾驶与网联车辆的未来，交叉路口将不再依赖红绿灯或传统路权规则，而需通过算法与通信协议优化交通流，但缺乏真实硬件验证。本文开发了一个测试平台，车辆通过无线连接与远程控制器交换信息并协调机动，展示了一个硬件在环（HiL）的智能交叉路口实现，使用SUMO交通模拟器仿真车辆位置，并采用面向车辆与路侧基础设施的真实软硬件组件运行协同协调算法。该演示实现了车辆不停车通过交叉路口的实时上下文与控制信息交换。

<h3 id="5">[5] Anechoic: Onsager-Corrected Parallel Annealing for Sub-0.1 ms Dense Max-Cut on an FPGA</h3>
- **arXiv**: [2610.13368](https://arxiv.org/abs/2610.13368)
- **Authors**: Seungki Hong, Kyeongwon Jeong, Taekwang Jang
- **Subjects**: cs.AR
- **Tags**: FPGA, Combinatorial Optimization
- **Code**: [code](https://github.com/skethz/anechoic)
- **Summary**: 伊辛机通过退火自旋网络求解组合优化问题，但在稠密问题上同步更新会产生“回声”效应，即自旋的先前状态通过邻居返回，导致大量翻转相互抵消。本文提出Anechoic，一种FPGA伊辛机，利用动力学平均场理论将回声识别为Onsager反应，并从每次决策中减去该修正，每步仅需一次种群计数。在K2000基准上，十二个250 MHz引擎在AMD Alveo V80上以99%概率在0.05毫秒内达到至少33,000的割，比最快已发表硬件快5.2倍，每解能耗5.4毫焦；在22纳米ASIC上预计约10微秒，快26倍。

<h3 id="6">[6] A Hybrid and Hierarchical Ray Tracing Method for Efficient 3D Gaussian Rendering</h3>
- **arXiv**: [2610.13498](https://arxiv.org/abs/2610.13498)
- **Authors**: Tiancheng Zhao, Sixu Li, Yuzhou Chen, Hengyu Ding, Zhiming Pan, Chaojian Li
- **Subjects**: cs.AR; cs.GR
- **Tags**: 3D Gaussian Splatting, Hardware Architecture
- **Summary**: 3D高斯泼溅（3DGS）虽能实时重建与渲染，但基于光追的3DGS面临三大挑战：大量高斯原语空间分布高度不均导致负载失衡、相邻像素光线遍历路径高度相似造成冗余、以及高斯与三角形混合求交负载异构。本文提出H2-Ray混合分层光追架构，包含负载均衡空间BVH（LB-SBVH）、光线簇路径复用（RCPR）和统一求交引擎（UIE），后者通过模式复用数据通路共享40%浮点单元。在8个场景中，H2-Ray在NVIDIA RTX A5000上相比RaySplats取得3.77倍几何平均加速，最高9.26倍。

<h3 id="7">[7] Rethinking Neural Nonlinearity as Gating</h3>
- **arXiv**: [2607.03148](https://arxiv.org/abs/2607.03148) (cross-listed)
- **Authors**: Muhammad Sabih, Frank Hannig, Jürgen Teich
- **Subjects**: cs.LG; cs.AI; cs.AR
- **Tags**: Neural Architecture, Compute-in-Memory
- **Summary**: 激活函数通常被视为实现神经网络非线性与通用逼近能力的必要原语，本文则表明输入条件化的阈值门控分支同样可作为通用原语实现非线性。作者证明标准激活函数（ReLU、PReLU、Hardtanh、SiLU、Sigmoid、Tanh、GELU）均为单一阈值门控（TG）原语的实例，softmax也可通过逐元素Sigmoid形式精确转换，并在CNN、Transformer和循环网络上无需重训练即可保持性能。TG还支持从零训练以提升模型压缩与性能、缩短训练时间，并提出“最小分支定理”关联所需最少分支数与可训练性，同时映射到模拟存内计算的统一实现以缓解ADC/DAC瓶颈。

<h3 id="8">[8] Power, Performance, and Area of HPC-Based Malware Detectors: An FPGA and Open-PDK ASIC Study</h3>
- **arXiv**: [2610.12795](https://arxiv.org/abs/2610.12795) (cross-listed)
- **Authors**: Alireza Abolhasani Zeraatkar, Parnian Shabani Kamran, Parsa Mirfasihi, Saleh Khalaj Monfared, Hussain Al-Asaad
- **Subjects**: cs.CR; cs.AR
- **Tags**: Malware Detection, Hardware Security
- **Summary**: 基于硬件性能计数器（HPC）的硬件恶意软件检测器（HMD）虽已知集成分类器检测指标更优，但其面积、功耗与时序成本尚不明确。本文构建了覆盖多种分类器族、可变HPC集合与集成学习方法的综合设计空间，并设计流水线重建训练模型、生成可综合RTL、对照位精确黄金模型验证并评估实现。结果表明，基于树与规则的检测器检测性能最高，面积比基于函数的分类器低近一个数量级、能耗低数倍；将HPC输入数减少至处理器并发计数器限制内可保持检测性能，同时显著降低面积、功耗与延迟。

<h3 id="9">[9] Characterizing CPU-GPU Memory Sharing over Unified Memory Architecture</h3>
- **arXiv**: [2610.13125](https://arxiv.org/abs/2610.13125) (cross-listed)
- **Authors**: Jinrong Yang, Zimeng Wang, Rong Chen, Haibo Chen
- **Subjects**: cs.OS; cs.AR
- **Tags**: Heterogeneous Computing, GPU Computing
- **Venue**: EuroSys 2027
- **Summary**: 统一内存架构（UMA）虽让CPU与GPU共享同一物理内存，但其复杂性与不透明性常导致应用退回低效拷贝或错误直访，损害性能甚至正确性。本文对四个平台上的CPU-GPU内存共享进行了涵盖数据面传输与控制面协调的全面研究，提炼出四条发现并据此实现可移植库libumsh。在九个真实系统上，libumsh将数据面时间降低16-75%，控制面开销降低7-90%。

<h3 id="11">[11] Breaking Memory Bottlenecks in Quantum Control Systems for More Precise Experiments and Higher Throughput Computing</h3>
- **arXiv**: [2608.06318](https://arxiv.org/abs/2608.06318) (replaced)
- **Authors**: Yicheng Guang, Neel Vora, Yilun Xu, Yueqi Chen, Gang Huang
- **Subjects**: cs.AR; cs.ET
- **Tags**: Quantum Computing, Hardware Acceleration
- **Summary**: 量子控制系统的片上BRAM容量有限且DRAM延迟不确定，形成内存瓶颈，阻碍了更深入的器件表征实验与更高电路吞吐。本文提出Ant-Q，一种面向QubiC 2.0控制系统的内存层次设计，将DRAM与BRAM集成以支持流水线量子电路执行，并在电路时长超过下一次填充时保持电路间时序确定性。在基准测试中，Ant-Q使板级超出电路执行的时间占比从18.91%-104.54%降至至多0.53%，30电路批次的板级吞吐提升51.06%（对比原版基线为59.90%），并成功执行5101个Clifford序列与100秒无中断Ramsey记录。
