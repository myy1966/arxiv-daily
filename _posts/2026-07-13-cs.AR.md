<h3 id="1">[1] StreamDQ: Near-Memory Weight DeQuantization in Custom HBM for Scalable AI Inference Acceleration</h3>
- **arXiv**: [2607.08993](https://arxiv.org/abs/2607.08993)
- **Authors**: Minki Jeong, Daegun Yoon, Soohong Ahn, Seungyong Lee, Nameun Kang, Hyeonseok Ju, Ieryung Park, Joonseop Sim, Youngpyo Joo, Hoshik Kim
- **Subjects**: cs.AR
- **Tags**: LLM Serving, Memory Architecture, Energy Efficiency
- **Summary**: 问题：GPU上基于CUDA核心的反量化带来大量指令开销、片内流量和流水线停顿，成为LLM推理瓶颈。方法：提出StreamDQ，在HBM基片中集成紧凑的反量化块（DQB），在内存子系统中实时反量化，消除GPU侧反量化。结果：混合精度GEMM加速比达7.08倍，能耗降低90.23%；端到端LLM推理延迟降低54.68%，解码吞吐量提升2.20倍。

<h3 id="2">[2] Accelerating GPU Inference of Large Language Models with Moderately Unstructured Sparse Weight Matrices</h3>
- **arXiv**: [2607.08786](https://arxiv.org/abs/2607.08786) (cross-listed)
- **Authors**: Tao Lu, Haoyu Wang, Zonghui Wang, Keshen Xiang, Jiaheng Zhang, Wenzhi Chen
- **Subjects**: cs.LG; cs.AI; cs.AR
- **Tags**: LLM Inference, GPU Computing, Sparse Matrix Multiplication
- **Code**: [code](https://github.com/moui0/cudac)
- **Summary**: 问题：中等非结构化稀疏度（约50%）下，现有稀疏矩阵乘法（SpMM）GPU核无法超越稠密矩阵乘法，制约LLM推理加速。方法：提出三层矩阵存储格式（Sparse-TC层、Slot-Filling压缩层、轻量Residual层），并设计联合利用稀疏张量核心和CUDA核心的SpMM核。结果：首次在现代HBM GPU上超越稠密矩阵乘法，核级加速达1.64倍，端到端推理速度相比FlashLLM提升1.41倍。

<h3 id="3">[3] On-Device Adaptive Battery Power Prediction for Electric Vehicles</h3>
- **arXiv**: [2607.09400](https://arxiv.org/abs/2607.09400) (cross-listed)
- **Authors**: Avik Bhatnagar, Anton Paule, Tobias Schuermann, Sebastian Reiter, Oliver Bringmann
- **Subjects**: cs.LG; cs.AI; cs.AR; cs.PF
- **Tags**: Time Series Forecasting, Battery Research, On-Device Learning
- **Venue**: IEEE EdgeCom 2025
- **Summary**: 问题：电动汽车电池功率预测中，深度学习模型在数据分布偏移时性能下降，且车载系统资源受限。方法：将预训练模型转换为可自适应版本，保留关键超参数知识，并研究在线和离线两种自适应策略。结果：在线和离线自适应分别降低平均绝对误差7.49%和14.88%，显著优于非自适应部署。

<h3 id="4">[4] LLM for EDA in Front-End Design: Challenges and Opportunities</h3>
- **arXiv**: [2607.09616](https://arxiv.org/abs/2607.09616) (cross-listed)
- **Authors**: Kangwei Xu, Bing Li, Ulf Schlichtmann
- **Subjects**: cs.ET; cs.AR; cs.LG; eess.SY
- **Tags**: LLM for EDA, LLM Agent, Survey
- **Summary**: 问题：芯片前端设计面临复杂度高、上市时间压力大等瓶颈，传统EDA工具难以满足需求。方法：综述LLM在EDA前端设计中的应用，讨论从局部辅助到自主代理式执行的演进，回顾电路生成、测试平台构建、高层次综合等任务进展。结果：提出关键挑战与未来机遇，为利用代理式AI技术推进EDA提供系统视角。
