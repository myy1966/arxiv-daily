<h3 id="1">[1] The Fallacy of Independent Ceilings: Characterizing Coupled Load-Branch Stall Interaction</h3>
- **arXiv**: [2608.11380](https://arxiv.org/abs/2608.11380)
- **Authors**: Matthew Constant, Resit Sendag
- **Subjects**: cs.AR; cs.PF
- **Tags**: Branch Prediction, Cache Policy, Performance Modeling
- **Summary**: 针对分支预测错误与数据缓存缺失被分别评估为独立瓶颈、导致性能上限被低估的问题，提出共生停顿延迟（SSL）与联合加速协同（JSS）度量框架，并设计轻量级MPKI筛查指标SSO。在53个工作负载中70%表现出可测量的耦合（JSS\>1），SSO\>20时JSS达1.23-3.29，证明独立完美模式在多类不规则负载下会低估联合优化收益。

<h3 id="2">[2] Uni-SFU: Algorithm-HW Co-Design for Universal SFUs via Mixed-Degree Piecewise Approximation</h3>
- **arXiv**: [2608.11577](https://arxiv.org/abs/2608.11577)
- **Authors**: Miao Sun, Yucheng Huang, Mingcong Cao, Jaehyun Park, Partha Pratim Pande, Umit Y. Ogras
- **Subjects**: cs.AR
- **Tags**: Hardware Acceleration, Approximate Computing, Activation Function
- **Summary**: 针对现有特殊函数单元（SFU）对各激活函数独立使用固定阶多项式与均匀分段导致硬件冗余和精度次优的问题，提出Uni-SFU算法-硬件协同设计框架，通过联合搜索为不同目标函数分配混合阶多项式与非均匀分段，并由RTL面积成本模型指导统一硬件配置。在700多个网络变体和三个NLP模型上，MSE低于8.22x10^-8，top-1精度损失不超过1.02%，在GF 22nm下面积仅6800μm²，优于SOTA。

<h3 id="3">[3] A Full-Stack Characterization of High-Bandwidth Flash for KV-Centric LLM Serving</h3>
- **arXiv**: [2608.11668](https://arxiv.org/abs/2608.11668)
- **Authors**: Zhuoran Li, Zhuohang Bian, Xin Huang, Yibo Zhao, Guangyu Sun, Youwei Zhuo
- **Subjects**: cs.AR
- **Tags**: LLM Serving, KV Cache, Storage Systems
- **Summary**: 针对将高带宽闪存（HBF）直接替换SSD用于KV卸载的常见思路，通过扩展TokenSim和四段生产轨迹进行全栈表征，发现该替代会使服务变差。原因是快速远层仅在读I/O为瓶颈、读多于写且带宽可持续三个条件同时成立时有用，而瞬态KV均不满足；结果端到端延迟上升2-5.5倍，SLO goodput下降1.1-2.7倍。因此HBF应作为选择性、复用感知、写入预算且热协调的层级，而非SSD替代品。

- **Tags**: LLM Inference, Quantization, GPU Computing
- **Summary**: 针对NVIDIA Blackwell Ultra规格书标称FP8:INT8约30:1但实际整数张量核心路径缺失的问题，从PTX ISA、CUTLASS、vLLM和SGLang四层堆栈进行审计，发现各层一致撤除INT8支持。结果表明量化格式的可用性是整个堆栈的属性而非规格表或模型属性；INT8在数据表上名义存在，但默认情况下在该硬件上不可部署。
