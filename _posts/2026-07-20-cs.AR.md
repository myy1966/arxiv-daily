<h3 id="1">[1] RTL-Sequencer: Towards Scalable RTL Timing Prediction with the Sequence-based Paradigm</h3>
- **arXiv**: [2607.15830](https://arxiv.org/abs/2607.15830)
- **Authors**: Ziyan Guo, Wenji Fang, Wenkai Li, Yuchao Wu, Shang Liu, Zhiyao Xie
- **Subjects**: cs.AR; cs.AI; cs.LG
- **Tags**: RTL Timing Prediction, EDA
- **Venue**: Design Automation Conference (DAC) 2026
- **Summary**: 现有基于图的方法在RTL时序预测中面临感受野有限、复杂度高及缺乏信号方向性等问题。本文提出序列化范式RTL-Sequencer，通过广度优先遍历线性化逻辑锥并应用线性序列模型，结合序列混洗、双向建模、可微建模及混合图-序列架构四种技术。实验表明，该方法在时序预测精度上显著超越现有基线。

<h3 id="2">[2] DSTAR: Accelerating Diffusion Transformers via Spatial and Temporal Redundancy Reduction</h3>
- **arXiv**: [2607.15846](https://arxiv.org/abs/2607.15846)
- **Authors**: Chi Zhang, Jieru Zhao, Yu Feng, Chen Zhang, Quan Chen, Minyi Guo
- **Subjects**: cs.AR
- **Tags**: Diffusion Model, Model Compression, Hardware-Software Co-design
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 扩散Transformer（DiT）的多轮推理导致高延迟和高能耗，现有加速方法多忽略其特有特征。本文提出软硬件协同设计框架DSTAR，包括细粒度混合精度量化、稀疏注意力重用机制及专用硬件加速器。在7种典型DiT上，相比A100 GPU实现最高7.33倍延迟加速和41.89倍能耗节省，且无精度损失。

<h3 id="3">[3] From Patterns to Parsers: Automatic Generation of Efficient Hardware Parsers for FPGAs</h3>
- **arXiv**: [2607.16058](https://arxiv.org/abs/2607.16058)
- **Authors**: Tushar Garg, Andrew Boutros
- **Subjects**: cs.AR
- **Tags**: FPGA, RTL Generation, Network Protocol
- **Summary**: 现有硬件解析器生成器难以支持范围验证、取反等复杂模式匹配。本文提出开源工具，通过解析中间表示（PIR）解耦前端与RTL生成后端，并引入自定义符号令牌扩展模式匹配能力。生成的以太网解析器相比先前工作实现高达226%的频率提升和97%的FPGA资源节省。

- **Tags**: Systolic Array, Fault Tolerance, Quantization
- **Summary**: 嵌入式设备上部署的深度学习模型易受故障注入攻击，现有量化方案要么静态且功耗高，要么动态但不安全。本文提出基于从左到右算术的实时自适应精度量化方法，结合灵敏度分析动态调整精度，并设计脉动阵列硬件实现MSB优先计算。软件部分已完成，硬件正在开发中。

<h3 id="5">[5] CoG-Guided Weight Correction for Fault-Tolerant Deep Neural Networks</h3>
- **arXiv**: [2607.15753](https://arxiv.org/abs/2607.15753) (cross-listed)
- **Authors**: Bahram Parchekani, Samira Nazari, Ali Azarpeyvand, Mohammad Hasan Ahmadilivani, Tara Ghasempouri, Jaan Raik
- **Subjects**: cs.LG; cs.AR; math.NA
- **Tags**: Fault Tolerance, Weight Correction, Hardware Reliability
- **Summary**: 深度神经网络权重易受硬件故障影响，传统校正方法需要重训练或修改架构。本文提出重心（CoG）引导的权重校正方法，利用距离感知规则检测和修正故障权重。在LSTM和CNN网络上，故障容忍度提升最高达230倍（StageNet）和49.55倍（ResNet-18），无需重训练。

- **Subjects**: cs.CR; cs.AR
- **Tags**: Hardware Simulation, Side-Channel Analysis, FPGA
- **Summary**: 现有功能验证模拟器不适用于侧信道分析所需的大量短迹线收集。本文提出开源Verilog模拟器Vogls，结合编译代码性能、全时序仿真和细粒度状态控制，并提供Python接口支持暂停、分支等操作。在栅级AES设计上比Icarus快5.9倍，同时成功演示了差分功耗分析攻击。

<h3 id="7">[7] Reducing Power Consumption of Embedded Dynamic Memories with ECCs</h3>
- **arXiv**: [2607.16042](https://arxiv.org/abs/2607.16042) (cross-listed)
- **Authors**: Wenqing Song, Yifei Shen, Andreas Burg
- **Subjects**: cs.IT; cs.AR
- **Tags**: Memory Architecture, Energy Efficiency, Error Correction Code
- **Summary**: 增益单元嵌入式DRAM因保持时间变化需要频繁刷新，纠错码可掩盖弱单元错误但会引入额外能耗。本文提出ECC选择方法，结合刷新间隔模型和功耗分析，在给定良率约束下识别最低功耗ECC配置。在不同带宽和活动因子下，总功耗降低46.8%至94.8%。
