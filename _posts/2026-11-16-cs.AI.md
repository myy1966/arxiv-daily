<h3 id="1">[1] When Should LLM Agents Forget? Memory Filtering Under Query-Critical Resolver Errors</h3>
- **arXiv**: [2611.17338](https://arxiv.org/abs/2611.17338)
- **Authors**: Samarth Vinayaka
- **Subjects**: cs.AI
- **Tags**: Agent Memory, LLM Memory
- **Summary**: 该论文研究LLM记忆系统中将事实判定为过时后硬删除的做法，指出当解析器错误删除了查询关键事实时，这种硬过滤会降低下游准确率。作者通过受控敏感性实验发现，硬删除的收益从完美解析下的+0.186至+0.230变为最低可靠性下的-0.176至-0.181，且误删比误留造成更严重的退化；一个部署匹配的门控在102/102校准/测试划分上达到0.655准确率，接近测试信息oracle的0.662。作者主张将删除视为代价敏感决策，在无法验证时默认采用无标签保留。
