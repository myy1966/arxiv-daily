<h3 id="1">[1] NDS: Programmer-Free Offload of High-Performance Near Data Strands</h3>
- **arXiv**: [2609.38454](https://arxiv.org/abs/2609.38454)
- **Authors**: Shreyas Singh, Pratyush Nandi, Lin Jia, Shankar Balachandran, Rajeev Balasubramonian
- **Subjects**: cs.AR
- **Tags**: Near-Data Processing, Hardware Acceleration
- **Summary**: 近数据处理（NDP）虽能缓解数据搬运瓶颈，但多数方案对软件栈、数据布局或硬件要求苛刻，难以推广。本文提出 Near Data Strands（NDS）框架，以模块化硬件为中心的方式自动识别可卸载循环、分解为并行执行链、生成高性能指令调度并完成数据编排，无需程序员或软件栈介入即可处理未修改的二进制程序。实验表明，NDS 相比单核主机基线取得 3.14 倍几何平均加速，相比 8 核并行变体取得 1.82 倍加速，且随循环重复调用摊销卸载开销，收益进一步增长。

<h3 id="2">[2] Structure-augmented LLMs for High-Level Synthesis Pragma Optimization</h3>
- **arXiv**: [2609.38601](https://arxiv.org/abs/2609.38601)
- **Authors**: Haocheng Xu, Ye Qiao, Phyo Pyae Moe Aung, Alok Mishra, Pavana Prakash, Rolando Pablo Hong Enriquez, Adam Han Wu, Zhiheng Chen, Dejan Milojicic, Sitao Huang
- **Subjects**: cs.AR
- **Tags**: High-Level Synthesis, LLM for EDA
- **Summary**: 高层综合（HLS）中 pragma 插入质量高度依赖专家对循环嵌套、数据依赖和内存布局的推理，而现有大语言模型缺乏显式程序结构感知能力。本文提出 PRISM，一种结构增强的 LLM，将抽象语法树（AST）、控制流图（CFG）和数据流图（DFG）三种层次化程序表示注入预训练冻结代码 LLM 的特定 Transformer 层，并通过交叉注意力门控在结构信号无用时可回退到预训练表示。在 HLS-Eval 零样本评测中，PRISM 合成的内核数量是 Llama3-8B 的 3.5 倍（26.9% vs. 7.7%），成功内核的设计几何平均速度比 GPT-5-mini 快 2.31 倍，在智能体流程中将 HLS-Eval 套件的平均归一化改进提升至 26.4%。

<h3 id="3">[3] Exact Diagonal Completion on Reachable Subspaces: Application to QAOA Placement</h3>
- **arXiv**: [2609.38734](https://arxiv.org/abs/2609.38734) (cross-listed)
- **Authors**: Owen Friedewald, Ali Shiri Sichani, Chi-Ren Shyu
- **Subjects**: cs.AR; cs.ET
- **Tags**: Quantum Computing, Combinatorial Optimization
- **Summary**: 量子算法中未使用的编码状态为简化电路提供了机会，但如何在不改变理想计算的前提下优化对角算子条目尚待研究。本文研究量子近似优化算法（QAOA）在布局问题中的精确对角补全，利用保持置换的寄存器交换，通过加权 ℓ1 优化 Walsh 系数和仅需 O(√m) 项的稀疏递推构造精确曼哈顿距离算子，避免 O(m⁴) 的稠密约束存储。在 160 种几何构型中，加权 ℓ1 补全在全部 96 个含未使用二进制码的案例中均减少了 CX 门数量；在独立 60 案例队列中，相对于虚拟坐标扩展的中位减少量在 6、9、12 个位点分别为 28.0%、53.9%、21.6%，但通用对角综合下减少量降至 10.9%、1.3%、0.7%，表明效果依赖编译器。

<h3 id="4">[4] Characterizing High Bandwidth Flash for LLM Serving</h3>
- **arXiv**: [2609.39131](https://arxiv.org/abs/2609.39131) (cross-listed)
- **Authors**: Zack Yu, Chloe Wong, Coleman Hooper, Minjae Lee, Wonjun Kang, Youngjin Cho, Michael W. Mahoney, Yakun Sophia Shao, Kurt Keutzer, Amir Gholami
- **Subjects**: cs.LG; cs.AR; cs.DC
- **Tags**: LLM Serving, Memory Architecture
- **Summary**: 大语言模型（LLM）服务需要大量内存存储模型权重和 KV 缓存，随着模型增大和上下文变长，内存容量与带宽成为瓶颈，而智能体工作负载因重复交互进一步加剧压力。本文评估高带宽闪存（HBF）用于高吞吐智能体服务，提出 HBM-HBF-主机分层存储系统和缓冲缓存感知调度，并通过轨迹驱动仿真分析性能、能耗和 HBF 写入寿命。实验显示，最快的 HBF 增强系统相比仅 HBM 系统将完成时间减少 36.1-87.0%，建模能耗节省达 55.8%，缓冲缓存感知调度将估计的 HBF 写入寿命从 4.77 年延长至 14.82 年。

<h3 id="5">[5] STELLA: A 16nm Spatio-Temporal Elastic Low-Latency CGRA for Multi-Stage Pipelined Applications</h3>
- **arXiv**: [2609.39703](https://arxiv.org/abs/2609.39703) (cross-listed)
- **Authors**: Jun Yin, Chao Fang, Ryan Antonio, Xiaoling Yi, Yunhao Deng, Fanchen Kong, Marian Verhelst
- **Subjects**: eess.SY; cs.AR
- **Tags**: Hardware Accelerator, Efficient Architecture
- **Summary**: 新兴非矩阵机器学习内核（如 LayerNorm、GeLU、FFT 或循环卷积）需要低延迟、高能效的空间加速器，而现有以 MatMul 为中心的阵列难以满足。本文提出 STELLA，一款 16nm 时空弹性粗粒度可重构阵列（CGRA），具备快速配置路径、每 PE 硬件循环控制以及低延迟深度流水弹性织物和时空数据复用。STELLA 在 850 MHz 下达到 110 GOPS/mm²，相比基线 CGRA 将有效内核吞吐量提升 4.84-7.14 倍。

- **Authors**: Alhad Daftardar, Jianqiao Mo, Joey Ah-kiow, Benedikt Bünz, Siddharth Garg, Brandon Reagen
- **Subjects**: cs.AR; cs.CR
- **Tags**: Zero-Knowledge Proof, Hardware Acceleration
- **Venue**: 32nd IEEE International Symposium on High-Performance Computer Architecture (HPCA-32), 2026
- **Summary**: 零知识证明（ZKP）在安全隐私计算中潜力巨大，但证明生成的计算开销极高，且现代协议中通过 SumCheck 支持复杂高阶门是一大挑战。本文提出 zkPHIRE，一种可编程全系统加速器，其核心单元通过 SumCheck 高效处理任意自定义门，并加速 HyperPlonk 协议。该单元在多种门类型上相比 CPU 版 SumCheck 取得超过 1000 倍几何平均加速；zkPHIRE 相比 CPU 取得 1486 倍几何平均加速，在等面积下相比最先进方案取得 11.87 倍加速，可扩展至 2³⁰ 以上约束并保持 4-5 KB 的小证明尺寸。

<h3 id="7">[7] ITHICA: Intra-Thread Instruction Checking Approach for Defect-Induced Silent Data Corruptions</h3>

- **Authors**: Ioanna Vavelidou, Subho S. Banerjee, Eric X. Liu, Mike Fuller, Subhasish Mitra, Caroline Trippel
- **Subjects**: cs.AR; cs.SE
- **Tags**: Hardware Reliability, Fault Diagnosis
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 超大规模数据中心报告了疑似由硅制造缺陷引起的静默数据损坏（SDC），威胁数据中心可靠性，而现有制造测试难以捕获最隐蔽的缺陷。本文提出 ITHICA，一种通过插入线程内指令级错误检查（主要利用指令复制和输出比较）从任意程序自动生成功能性测试的方法与工具，其关键洞察是最有害缺陷会导致同一线程内相同指令在相同输入下因执行上下文不同而产生不一致输出。ITHICA 将工业超大规模测试、数据中心程序和常用库转化为功能测试，在超过 3000 台 CPU 服务器上评估，检测到的缺陷服务器比基线工业检查多 39%，并对先前机队研究结论提出挑战。

<h3 id="8">[8] HBFSim: Fast and Faithful Simulation of High-Bandwidth Flash Under Real GPU Execution</h3>
- **arXiv**: [2609.09800](https://arxiv.org/abs/2609.09800) (replaced)
- **Authors**: Yanpeng Hu, Yiwei Yang, Yuanwu Zhu, Yusheng Zheng, Andi Quinn, Wei Zhang
- **Subjects**: cs.AR; cs.ET
- **Tags**: Simulation, LLM Inference
- **Code**: [code](https://github.com/SlugLab/hbfsim/)
- **Summary**: 高带宽闪存（HBF）将高容量 NAND 置于 HBM 旁以缓解 LLM 推理的内存容量瓶颈，但在硬件可用前无法评估其系统级行为，周期级 GPU 模拟器太慢而轨迹重放无法捕捉不同 HBM-HBF 配置引起的分配、迁移和执行变化。本文提出 HBFSim，一个开源 HBF 模拟器，在真实 GPU 上执行 LLM 工作负载并在线建模 HBF 时序、热等行为，通过重写内核 PTX 并将注册地址范围内的访问路由到模拟器，支持异步 TMA 传输和超出物理 GPU 内存的容量。HBFSim 在普通内存、TMA 和容量模式测试中不影响模型运行，注入延迟与请求延迟误差在 0.152% 以内；对 Qwen3-30B 的实验揭示了封装加热、HBM-HBF 分配和共享 MoE 需求如何共同约束未来 HBF 加速器设计空间。

<h3 id="9">[9] Diagnosing Temporal Misalignment in Multichannel Time-Series Classification with Minimum Description Length</h3>
- **arXiv**: [2609.14595](https://arxiv.org/abs/2609.14595) (replaced)
- **Authors**: Sebastian Buschjäger, Michael Frichert, Daniel Kuhse, Jian-Jia Chen
- **Subjects**: cs.LG; cs.AI; cs.AR
- **Tags**: Time Series Classification, Time Series Analysis
- **Code**: [code](https://github.com/sbuschjaeger/mdl-temporal-misalignment)
- **Summary**: 多通道时间序列分类通常假设传感器流已同步，但延迟、时钟漂移和预处理会引入相对时移，现有同步方案多为硬件特定且难以追溯应用，导致同步问题未被发现且分类性能次优。本文提出一种与分类器和标签无关的最小描述长度（MDL）诊断方法，通过对传感器组施加候选时移并测量一组通道通过其余通道表示进行编码的效率来检测错位。在两个受控合成任务和九个真实数据集上的实验表明，该指标能揭示对齐结构并在部署漂移下恢复精度，对FordChallenge、Opportunity、PAMAP2和UCIActivity等基准的全数据集审计还发现了稳定的非零MDL最优值，揭示了传统评估未暴露的系统性偏移。

<h3 id="10">[10] Many Processors, Still One Computer: The Nested Parallel von Neumann Architecture and Nested BSP</h3>
- **arXiv**: [2609.16787](https://arxiv.org/abs/2609.16787) (replaced)
- **Authors**: Heng Liao
- **Subjects**: cs.DC; cs.AR
- **Tags**: High Performance Computing, Distributed Computing
- **Summary**: 大规模AI计算的核心挑战已不再是单个处理器性能，而是百万级处理器能否仍像一台计算机一样协同工作。本文提出两项扩展：将经典BSP递归嵌套为可在任意尺度成立的Nested BSP，以及将冯·诺依曼单机架构扩展为Nested Parallel von Neumann Architecture，即从芯片封装到自主区域的对等层级嵌套，并通过统一内存语义互连（Unified Bus）端到端连接，软件嵌套与硬件嵌套逐层对应，τ Scaling定律在各层折叠时间。文章分析了嵌套结构所服务的工作负载（以AI训练为主，也涵盖经典HPC），并描述了使嵌套物理化的硬件决策。
