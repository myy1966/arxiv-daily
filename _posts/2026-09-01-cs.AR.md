<h3 id="1">[1] High-Performance Low-Power Adiabatic Systolic Array Design in Advanced FinFET Nodes</h3>
- **arXiv**: [2608.30058](https://arxiv.org/abs/2608.30058)
- **Authors**: Jun Yin, Liangtao Dai, Yimin Gao, Mircea R. Stan
- **Subjects**: cs.AR
- **Tags**: Low Power, Energy Efficiency, Adiabatic Logic
- **Venue**: 44th IEEE International Conference on Computer Design (ICCD 2026)
- **Summary**: 该文针对传统绝热逻辑局限于低时钟频率的问题，提出在先进FinFET节点中设计绝热MAC脉动阵列，并集成谐振4相功率时钟发生器。在16nm FinFET工艺下，该设计在1GHz下实现了核心和系统级功耗分别降低42%和36%。

<h3 id="2">[2] FABO: Agent-Guided Discovery of Joint Breakpoint Optimization for Timing-Driven Routing Trees</h3>
- **arXiv**: [2608.30268](https://arxiv.org/abs/2608.30268)
- **Authors**: Shang Liu, Wenji Fang, Jing Wang, Hongxin Kong, Yao Lu, Zhiyao Xie
- **Subjects**: cs.AR
- **Tags**: LLM for EDA, Routing Optimization, Algorithm Discovery
- **Code**: [code](https://github.com/DevinShang/routing-FABO)
- **Summary**: 该文指出SALT构造算法在时序驱动布线树中逐路径修复的局限性，导致共享线过早分叉和重复布线。通过语言模型引导的搜索发现该问题，并提出FABO算法联合优化共享路径的分叉点。在129万网和20点延展容忍度下，平均线长降低最高0.83%，对30+引脚网降低2.66%，且FABO-FAST以1.3倍运行时间获得大部分收益。

<h3 id="3">[3] Scalable AXI4 Transaction Monitoring for Mixed-Criticality SoCs: From Phase-Level Precision to ID-Level Efficiency</h3>
- **arXiv**: [2608.30435](https://arxiv.org/abs/2608.30435)
- **Authors**: Chaoqun Liang, Thomas Benz, Alessandro Ottaviano, Michael Rogenmoser, Luca Benini, Angelo Garofalo, Davide Rossi
- **Subjects**: cs.AR
- **Tags**: Runtime Verification, Fault Tolerance, Fault Detection
- **Summary**: 该文针对AXI4互连的混合关键性SoC缺乏协议级超时机制，可能导致死锁和错过截止时间的问题，提出一种可配置硬件IP，通过切排隔离机制检测违规并恢复。设计了三种监测粒度（PLT、CLT、ILT），在12nm工艺下CLT和ILT分别降低面积36.7%和89.2%，且120万故障注入场景中无一漏检。

<h3 id="4">[4] Non-uniform Memory Partitioning For Low-Power Spiking Neural Networks</h3>
- **arXiv**: [2608.30444](https://arxiv.org/abs/2608.30444)
- **Authors**: Simon Richter, Darío Fernández Khatiboun, Maryam Sadeghi, Milad Zamani, Farshad Moradi
- **Subjects**: cs.AR
- **Tags**: Spiking Neural Network, Memory Architecture, Low Power
- **Summary**: 该文针对SNN中突触权重SRAM访问功耗占主导的问题，利用神经元发放率差异，将权重映射到非均匀大小的内存库。在28nm CMOS下，与传统设计相比，权重内存访问功耗降低高达61%，且面积开销比传统均匀分区低2.1倍。

- **Tags**: Low Power, PPA Optimization, Clock Gating
- **Venue**: IEEE UEMCON 2026
