<h3 id="1">[1] LLMET: Enabling Cross-Layer Evaluation of Emerging M3D Memories for Energy-Efficient LLM Serving</h3>
- **arXiv**: [2607.26491](https://arxiv.org/abs/2607.26491)
- **Authors**: Ming-Yen Lee, Hanchen Yang, Faaiq Waqar, Harsono Simka, Tushar Krishna, Muhammed Ahosan Ul Karim, Shimeng Yu
- **Subjects**: cs.AR; cs.AI; cs.ET; cs.LG
- **Tags**: LLM Inference, Memory Architecture
- **Summary**: 本文针对大型语言模型（LLM）服务中因数据移动导致的能耗问题，提出并验证了一个跨层仿真框架LLMET，用于评估新型M3D片上存储器对LLM服务能效的影响。研究发现，将L2缓存从40MB扩展到1GB可降低Llama3.1-70B预填阶段44%的芯片能耗。结果表明，超大容量片上存储器对于节能LLM服务系统具有巨大潜力。

<h3 id="2">[2] NELSSA: A GPU-PNM Heterogeneous System for Mixed-Length LLM Serving via Length-based Request Placement</h3>
- **arXiv**: [2607.26633](https://arxiv.org/abs/2607.26633)
- **Authors**: Sookyung Choi, Seungyong Lee, Kangkyu Park, Yunseo Chun, Junseok Lee, Hyeongseok Gwak, Myunghyun Rhee, Euiseok Kim, Donguk Moon, Kwangsik Shin, Guseul Heo, Youngpyo Joo, Hoshik Kim, Jongse Park
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Heterogeneous Computing, Near-Data Processing
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 针对GPU-centric架构在处理混合长度LLM请求时的低效问题，本文提出了NELSSA系统，将GPU与近内存处理（PNM）加速器集成，通过基于长度的请求放置策略将短上下文请求路由到GPU、长上下文请求路由到PNM。实验表明，NELSSA将解码吞吐量提升最高5.5倍，P99延迟降低最高15倍。

<h3 id="3">[3] A Low-Power Sparse Convolution Accelerator with Idle-First-Task-Assignment for Edge Vision</h3>
- **arXiv**: [2607.26835](https://arxiv.org/abs/2607.26835)
- **Authors**: Jingyue Zhuge, Johannes Partzsch, Christian Mayr
- **Subjects**: cs.AR
- **Tags**: Hardware Acceleration, Edge Computing, Sparse Convolution
- **Venue**: 2026 IEEE 8th International Conference on Artificial Intelligence Circuits and Systems (AICAS 2026)
- **Summary**: 针对边缘视觉监控系统在有限带宽和功耗下的图像处理挑战，本文设计了一款低功耗稀疏卷积加速器（16nm工艺），采用位图压缩和空闲优先任务分配（IFTA）动态调度策略。芯片核心面积仅0.5mm²，功耗12-16mW，在稀疏VGG16和MobileNetV2上分别实现6.5倍和2.8倍加速。

- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 针对DNN加速器中难以检测的缓慢故障（fail-slow），本文提出SLOTH框架，结合工作负载感知监测、在线迹压缩和拓扑感知排序算法，实现轻量级片上故障检测。存储开销平均降低115.9倍，检测准确率从69.68%提升至86.69%。

<h3 id="6">[6] NeuroPDE+: A Scalable Neuromorphic PDE Accelerator Based on Spintronic and Ferroelectric Devices</h3>
- **arXiv**: [2603.28042](https://arxiv.org/abs/2603.28042) (replaced)
- **Authors**: Siqing Fu, Lizhou Wu, Tiejun Li, Xuchao Xie, Sheng Ma, Jianmin Zhang, Wei Chen, Yunping Zhao
- **Subjects**: cs.AR
- **Tags**: Neuromorphic Computing, Scientific Computing, Hardware Acceleration
- **Summary**: 针对PDE求解的维度灾难、数据驱动代理外推能力差及算法硬件鸿沟，本文提出基于自旋电子和铁电器件的神经形态PDE加速器NeuroPDE+。通过扩散跟踪单元和散射跟踪单元，在稳态热传导和粒子输运问题中均方误差低于1e-2，DTU和STU分别实现315倍和1000倍加速。

- **Authors**: Zhiyu Zheng, Yiming Du, Ziyi Wang, Zhiang Wang
- **Subjects**: cs.AR
- **Tags**: EDA, Hardware Design, Design Space Exploration
- **Summary**: 针对开源EDA工具设计空间探索（DSE）局限于公开旋钮的问题，本文提出ReviewDSE框架，探索优化器内部的源级机制。在OpenROAD详细布局中，与黑盒DSE相比，ReviewDSE将后DPL半周长线长（HPWL）降低1.78%，并在运行时开销仅1.11倍时仍保持1.68%的降低。
