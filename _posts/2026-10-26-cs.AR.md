<h3 id="1">[1] TranSAGE: Automating Spatial Accelerator Generation for Large-Scale Transformer Models</h3>
- **arXiv**: [2610.32279](https://arxiv.org/abs/2610.32279)
- **Authors**: Chi Zhang, Yi Sun, Weichuang Zhang, Quan Chen, Jieru Zhao
- **Subjects**: cs.AR
- **Tags**: Hardware Accelerator, LLM Inference
- **Venue**: ASPLOS 2027
- **Code**: [code](https://github.com/sjtu-zhao-lab/TranSAGE)
- **Summary**: 针对大规模 Transformer 推理中空间加速器设计成本高、现有生成器仅支持单算子而忽略多算子流水的问题，提出基于编译器的 TranSAGE 框架，联合优化多算子流水调度并自动生成 RTL 实现。在四个代表性 LLM 上，相比商用 GPU/NPU 基线吞吐量最高提升 2.41 倍、能效提升 13.04 倍，相比 SOTA 加速器生成器吞吐量最高提升 11.33 倍、能效提升 6.07 倍。

<h3 id="2">[2] PARIS: Parallel Arithmetic Reduction and Integrated Selection for MSDF Inner Products</h3>
- **arXiv**: [2610.32410](https://arxiv.org/abs/2610.32410)
- **Authors**: Malik Zohaib Nisar, Ic-Pyo Hong, Dorit Merhof, Muhammad Usman
- **Subjects**: cs.AR
- **Tags**: Hardware Accelerator, Compute-in-Memory
- **Summary**: 现有 MSDF 加速器串行处理输入项，导致内积延迟随扇入增加。本文提出 PARIS 架构，通过并行位平面归约和共享进位保存残差选择消除输入项串行化，对 B 位操作数处理 B² 个位位置对且与扇入无关。45nm 下 784 通道 INT8 核心面积 0.008701 mm²、88 周期完成内积，两个 MNIST MLP 上算术加速 240.44 倍和 180.47 倍，算术能耗降低 98.89% 和 98.58%。

<h3 id="3">[3] Automated Multi-Line Bug Repair Using Model Checker Aided LLMs: A Case Study on RISC-V Processors</h3>
- **arXiv**: [2610.32597](https://arxiv.org/abs/2610.32597)
- **Authors**: Debleena Das, Chandan Kumar Jha, Muhammad Hassan, Rolf Drechsler, Ansuman Banerjee, Subhra K. Das, Amlan Chakrabarti
- **Subjects**: cs.AR; cs.SE
- **Tags**: Program Repair, RTL Verification
- **Summary**: RTL 功能验证中的调试修复耗时且现有 LLM 方法多针对单行 bug、开环且缺乏形式保证。本文提出结合 LLM、断言和模型检查器（JasperGold）的自动化 RTL 多行 bug 修复方法，用失败断言引导 LLM 生成补丁并形式验证。在 BRISC-V RISC-V 核上通过变异测试表明可修复 98% 单行 bug 和 93% 多行 bug，是首个在复杂 RISC-V 处理器上实现可扩展 LLM 辅助多行 RTL 修复的工作。

<h3 id="4">[4] Embodied Emissions of 2.5D and 3D Scaling in Chipletized GPUs for Low-Carbon AI</h3>
- **arXiv**: [2610.32830](https://arxiv.org/abs/2610.32830)
- **Authors**: Hannah Watson, Arjun Singh, Jennifer Stephenson, Job Soethoudt, Debjyoti Bhattacharjee, James Myers
- **Subjects**: cs.AR
- **Tags**: AI Sustainability, Hardware Architecture
- **Summary**: AI 工作负载增长推动 GPU 规模扩展，但封装选择对隐含碳排放的影响尚不明确。本文使用建模平台估算 2.5D 和 3D 芯片化 GPU 在计算单元和 HBM 容量翻倍时的隐含排放。结果显示 3D 扩展使隐含排放增加 89%，而 2.5D 扩展增加 141%，表明 3D 扩展是限制 GPU 扩展碳排放的更具吸引力的方案。

<h3 id="5">[5] Decode Late, Multiply Once: Rethinking the Dot Product for Quantized Weights</h3>
- **arXiv**: [2610.31913](https://arxiv.org/abs/2610.31913) (cross-listed)
- **Authors**: Jonathan Tapson
- **Subjects**: cs.LG; cs.AR
- **Tags**: Quantization, Hardware Accelerator
- **Summary**: 低比特权重网络的内积仍对每个元素使用一个乘法器。本文提出“延迟解码、一次乘法”的重构方法，用权重码作为地址偏移选择累加器，使长度 n、k 比特权重的点积仅需 n+2^k 次加法和至多 2^k 次解码与乘法，并设计 scatter-accumulate 处理单元替换 MAC。乘法器数量降低 n/2^k，权重内存最多减少 w_d/k，RTL 实现验证了整数精确等价且浮点误差不劣于传统流水线。

<h3 id="6">[6] A Resource-Efficient and Precision-Scalable FPGA Accelerator for Spiking Neural Networks Using Minifloat Arithmetic</h3>
- **arXiv**: [2610.32052](https://arxiv.org/abs/2610.32052) (cross-listed)
- **Authors**: Ali Mehrabi, Philip C. Jose
- **Subjects**: cs.NE; cs.AR
- **Tags**: Spiking Neural Network, FPGA
- **Summary**: 脉冲神经网络在边缘部署受限于传统浮点实现的算术复杂度、内存和功耗。本文提出基于参数化 minifloat 算术的精度可扩展、资源高效 SNN FPGA 加速器，统一数据通路支持 E8M23、E5M10、E5M6、E4M3 格式并共享算术资源。FPGA 结果表明降低 minifloat 精度可显著减少算术资源利用率和动态功耗，同时在循环事件分类网络上保持有竞争力的推理精度。

<h3 id="7">[7] Toward Open ISA Supercomputing: A Comparative Study of RISC-V, Arm, and x86 Architectures on HPC Workloads</h3>
- **arXiv**: [2610.32632](https://arxiv.org/abs/2610.32632) (cross-listed)
- **Authors**: Emanuele Venieri, Giacomo Madella, Gabriele Ceccolini, Simone Manoni, Federico Ficarelli, Filippo Barbari, Jenny Lynn Almerol, Elisabetta Boella, Nitin Shukla, Simone Bnà, Luca Benini, Andrea bartolini
- **Subjects**: cs.DC; cs.AR; cs.PF
- **Tags**: High Performance Computing, RISC-V
- **Summary**: RISC-V 作为 HPC 候选架构缺乏与 x86、Arm 在统一平台和方法下的可比评估，且少有考虑能效。本文用共同软件栈和方法比较 Sophgo SG2044、NVIDIA Grace 和 Intel Xeon Platinum 8480+ 在四个 HPC 基准和四个应用上的表现。SG2044 单核 FP64 达 8.02 GFLOP/s、64 核达 294 GFLOP/s，绝对性能比 Arm/x86 低 8-15 倍，但在 LLM 解码等负载上展现竞争性扩展和能效，64 核吞吐超过 Intel。

<h3 id="8">[8] HAWK: Heterogeneity-Aware KV Cache Transfer for Efficient GPU-NPU Phase-Disaggregated LLM Inference</h3>
- **arXiv**: [2610.29873](https://arxiv.org/abs/2610.29873) (replaced)
- **Authors**: Junhyeok Park, Jungeun Yoon, Kyungmin Kim, Hunsoon Lee, Shinyoung Ahn, Kangho Kim
- **Subjects**: cs.AR; cs.DC
- **Tags**: LLM Serving, KV Cache
- **Summary**: LLM 推理中 prefill 计算密集而 decode 内存密集，GPU 适合 prefill、NPU 适合 decode，但异构阶段分离面临跨设备 KV cache 传输的通信机制和布局差异挑战。本文提出 HAWK 传输机制，建立 RDMA 直传路径并在 NPU 侧分配布局感知缓冲区以消除重排。在商用 GPU/NPU 系统上，HAWK 在相同 SLO 下性能距纯 GPU 系统 7.88% 以内，能效提升最高 1.26 倍、成本效率提升最高 1.72 倍。

<h3 id="9">[9] MERA: A Mid-Circuit-Measurement Error-Aware Compilation Framework for Quantum Circuits</h3>
- **arXiv**: [2511.10921](https://arxiv.org/abs/2511.10921) (replaced)
- **Authors**: Ming Zhong, Zhemin Zhang, Xiangyu Ren, Chenghong Zhu, Siyuan Niu, Zhiding Liang
- **Subjects**: cs.AR
- **Tags**: Quantum Computing, Compiler Optimization
- **Venue**: ICCAD 2026
- **Summary**: 该论文针对量子电路中中途测量（MCM）引入的测量串扰、空闲量子比特退相干和重置不保真等误差，且现有编译器（如Qiskit-compiler和QR-Map）忽略MCM误差在量子比特间的差异，导致频繁MCM电路保真度下降的问题。作者提出MERA框架，通过轻量级分析获取稳定超过24小时的逐量子比特MCM误差分布，并将其融入布局、路由和调度阶段，同时结合上下文感知的动态解耦。实验表明，MERA在无额外SWAP开销下相比Qiskit-compiler（优化级别3）平均提升24.94%–80.48%的保真度，并使QR-Map生成电路的保真度平均提升29.26%（最高122.58%）。
