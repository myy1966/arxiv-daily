<h3 id="1">[1] RoadBlock: Rethinking GPU Tensor Core Microarchitecture for Emerging Microscaling Format Support</h3>
- **arXiv**: [2611.08526](https://arxiv.org/abs/2611.08526)
- **Authors**: Nikhil Rout, Blaise Tine
- **Subjects**: cs.AR
- **Tags**: Hardware Architecture, Quantization
- **Venue**: ACM International Conference on Parallel Architectures and Compilation Techniques (PACT), 2026
- **Summary**: 现有自定义 Microscaling (MX) 格式的硬件评估仅停留在独立 MAC 单元原型层面，忽略了真实 GPU Tensor Core 中的系统级集成开销。作者提出 RoadBlock，一个基于 RISC-V Vortex GPGPU 的开源框架，可对可编程 Tensor Core 中的自定义 MX 格式进行端到端精确建模，并将数据位宽、缩放因子大小和块大小作为可配置参数，自动推导任意格式的每线程元数据分块。该框架支持在流片前进行格式特定的困惑度-PPA 权衡评估。

<h3 id="2">[2] SAFTAC: Simulation-Augmented Fine-Tuning of Open-Source LLMs for Analog Circuit Design</h3>
- **arXiv**: [2611.08543](https://arxiv.org/abs/2611.08543)
- **Authors**: Junsheng Huang, Yifan Sun, Zhuoer Zhang, Ning Wei, Yening Liu, Michael Molter, Pavan Kumar Hanumolu, Elyse Rosenbaum, Bin Hu, Huan Zhang
- **Subjects**: cs.AR; cs.AI
- **Tags**: Circuit Design, Fine-Tuning
- **Venue**: NeurIPS 2026
- **Summary**: 模拟集成电路设计因拓扑、器件尺寸与性能紧密耦合而困难，现有基于 LLM 的方法要么在冻结模型上做推理时修正，要么仅在有限电路类型上训练且未直接利用仿真结果作为训练信号，同时缺乏端到端规格条件设计的数据集。作者构建了覆盖 10 类模拟电路、8,626 个设计任务的大规模仿真数据集，并提出 SAFTAC 仿真增强微调框架，结合三阶段监督微调与仿真反馈增强的强化微调。在单次生成和带仿真反馈的两次生成设置下，分别比最强闭源 LLM 提升 15.9% 和 7.8%。

<h3 id="3">[3] Enabling Retraining-Free Accurate Inference in Analog Compute in Memory Accelerators</h3>
- **arXiv**: [2611.08693](https://arxiv.org/abs/2611.08693)
- **Authors**: George Karfakis, Puneet Gupta
- **Subjects**: cs.AR; cs.LG
- **Tags**: Compute-in-Memory, Inference Optimization
- **Summary**: 模拟存内计算加速器虽能大幅提升推理效率，但转换器与器件误差使预训练模型无法直接使用，而硬件感知重训练成本高昂。作者发现模拟误差取决于每层在阵列上的表示方式，且该表示可离线改变而不改变计算，据此提出输入中心化与面向模拟阵列的 Hadamard 旋转，使共享参考误差分散并将输入混合限制在单个阵列内。在 PCM 与 ReRAM 上的 CNN、ViT 及最大 14B 的 LLM 中，该方法无需训练任何权重即可将 ViT-B/16 从 37.4% 恢复至 82.9%、Phi-4 从 27.0% 恢复至 72.2%，均与浮点精度相差 2.2 个百分点以内。

<h3 id="4">[4] TwinHash: Two-Sided Object Identity Management for Time- and Energy-Efficient Agentic Workflows</h3>
- **arXiv**: [2611.09254](https://arxiv.org/abs/2611.09254)
- **Authors**: Sangbu Yun, Jung Gyu Min, Jin Hyun, Jeonghwan Ahn, Youngjoo Lee
- **Subjects**: cs.AR
- **Tags**: LLM Serving, Agentic AI
- **Venue**: IEEE HPCA 2027
- **Summary**: 智能体 AI 服务在 LLM 生成与外部工具执行之间交替，并频繁重访共享推理状态，造成工具输出、LLM 响应和 KV 前缀的大量冗余，而现有服务系统主要优化共享提示前缀，且简单的输入键缓存在不安全时会产生错误输出。作者提出 TwinHash 统一对象管理架构，为每个对象分配输入侧哈希键以识别重复请求、输出侧内容指纹以验证和定位存储状态，并配合类型特定的复用保护。在七个智能体框架和五个基准上，TwinHash 可复用高达 81% 的工具输出和 92% 的 LLM 响应，从 DRAM 取回被驱逐的 KV 前缀使 Qwen3-32B 的 TTFT 降低最多 5.6 倍，端到端墙钟时间降低最多 87%、能耗降低最多 81%。

<h3 id="5">[5] Memory as a Temporal Resource: Lifetime Contracts for Multi-Retention Systems</h3>
- **arXiv**: [2611.09518](https://arxiv.org/abs/2611.09518)
- **Authors**: Adrian Jackson
- **Subjects**: cs.AR
- **Tags**: Memory Architecture, Hardware-Software Co-design
- **Summary**: 计算机移动和重写的数据其有效生命周期从内层循环迭代到数年不等，但内存系统通常将保留时间视为固定的物理属性而隐藏起来。作者主张将所需生命周期作为算法、编程系统、控制器与器件之间的一等资源，并提出基于事件的有效性契约，将应用完成事件与保留类别选择和保护续期关联，使数据映射到为短暂、纪元或持久保留设计的同质阵列。论文给出基于 trace 的模拟器和 FPGA 原型以验证类别迁移。

<h3 id="6">[6] CPU Micro-Architectural Characteristic Sensitivity Study on CPU-Side Agentic Task Latency</h3>
- **arXiv**: [2611.08697](https://arxiv.org/abs/2611.08697) (cross-listed)
- **Authors**: Jack Adiletta, Shixin Ji, Zhuoping Yang, Peipei Zhou
- **Subjects**: cs.DC; cs.AR
- **Tags**: Edge Computing, Agent Evaluation
- **Summary**: 小型企业和个人用户为降低成本并保护数据隐私，倾向于在本地运行智能体，但边缘 CPU 的最优性能特征尚不清楚。作者研究了 CPU 核心频率、非核心频率、活跃物理核心数与超线程对单智能体和多智能体任务延迟的影响，在 Intel 边缘 CPU 上进行了八组实验。结果显示 P 核频率带来的中位延迟改善最大，从 2.5 GHz 提升至 5.5 GHz 时单智能体加速 1.154 倍、八并发智能体加速 1.341 倍，并开源了可复现的 CPU 侧延迟基准框架与数据集。

<h3 id="7">[7] Gain-Dependent Entropy Characterization of a Zener Avalanche Noise TRNG via Dual NIST Standards: Toward Low-Cost Hardware Entropy for ICS Deployments</h3>
- **arXiv**: [2611.08774](https://arxiv.org/abs/2611.08774) (cross-listed)
- **Authors**: Rishabh Das
- **Subjects**: cs.CR; cs.AR
- **Tags**: Hardware Security, IoT
- **Summary**: 基于齐纳雪崩噪声的真随机数发生器为工业控制系统和 IoT 边缘设备提供低成本熵源，但放大器增益、耦合电容与熵质量之间的关系在当前 NIST 标准下尚未被刻画。作者在五种增益配置和两种耦合电容下，使用每配置 14.4 亿原始比特，依据 NIST SP 800-22 与 SP 800-90B 进行全面熵评估，识别出由比较器饱和恢复动态导致的三阶段自相关结构。直流替代实验使开关活动降低约 97%，确认齐纳雪崩噪声是必要熵源，并找到在物料成本低于 5 美元时实现完美统计测试得分与合规最小熵的最优增益配置。

<h3 id="8">[8] Robust & Scalable Website Fingerprinting via Minimal DRAM Traffic</h3>
- **arXiv**: [2611.09422](https://arxiv.org/abs/2611.09422) (cross-listed)
- **Authors**: Shubham Roy, Samar Parwez, Biswabandan Panda
- **Subjects**: cs.CR; cs.AR
- **Tags**: Privacy, Side-Channel Analysis
- **Summary**: 网站指纹攻击可推断用户访问的网站并威胁隐私，但现有同址攻击如 sweep-counting 和 loop-counting 在多核系统上性能显著下降，例如 loop-counting 在 8 核上准确率 93%，在 24 核上降至 50%。作者提出 memory-chasing 攻击，利用指针追逐遍历造成的 DRAM 流量干扰，在固定间隔内计数 DRAM 访问以生成可分类的独特轨迹。在前 50 个网站上，该攻击在 24 核系统上达到 96% 准确率，跨多 CCD 为 86%，跨多插槽为 80%，开放世界设置为 97%，并在多种硬件、浏览器、操作系统、隔离机制和防御措施下表现出鲁棒性与可扩展性。
