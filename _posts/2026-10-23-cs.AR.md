<h3 id="1">[1] Verified DRAM Address Mapping Reverse Engineering with Threshold Sweep</h3>
- **arXiv**: [2610.30397](https://arxiv.org/abs/2610.30397)
- **Authors**: Hewen Zhang, Ian G. Harris
- **Subjects**: cs.AR
- **Tags**: Reverse Engineering, Hardware Security
- **Venue**: DFTS 2026
- **Summary**: 该论文针对嵌入式LPDDR5系统上DRAM地址映射函数逆向工程缺乏系统验证的问题，提出端到端软件流水线：先构建延迟直方图并通过阈值扫描获得同bank地址对，再用Knock-Knock式线性约束求解器与GF(2) RREF恢复bank掩码，最后通过组验证和单函数验证两阶段检验正确性。该工作系统记录每个候选阈值的掩码与验证指标，支持在ARM嵌入式设备上更稳健地选择bank掩码，并为后续Rowhammer分析提供高效方法。

<h3 id="2">[2] Proba: A High-Performance, Low-Traffic Probabilistic Spatial Memory Streaming Prefetcher</h3>
- **arXiv**: [2610.30448](https://arxiv.org/abs/2610.30448)
- **Authors**: Yinting Huang, Jacky Wong, Sam Ainsworth
- **Subjects**: cs.AR
- **Tags**: Memory Architecture, Hardware Architecture
- **Summary**: 现有SMS空间内存预取器对激进程度控制粗糙、难以适应动态程序行为，该文提出反馈驱动的Proba预取器，结合概率模式更新、边际精度决策与多触发特征模式累积，实现细粒度精度-覆盖率权衡。当精度下降时降低激进程度、精度上升时扩大覆盖，Proba在单线程吞吐不受损的前提下取得优于其他SMS预取器的加速比，并在多核与DRAM受限场景下显著降低DRAM流量。

<h3 id="3">[3] FIGFLEX: A Mixed-Precision FP-INT GEMM Accelerator Co-Designed with Low-Bit LLM Quantization</h3>
- **arXiv**: [2610.30480](https://arxiv.org/abs/2610.30480)
- **Authors**: Faraz Tahmasebi, Haocheng Xu, Andrew Trauger, Yomal Perera, Zhenyu Tang, Nael Chowdhury, Sitao Huang
- **Subjects**: cs.AR; cs.LG
- **Tags**: Quantization, Hardware Accelerator
- **Summary**: 权重仅量化将LLM主要负载变为FP-INT GEMM，但现有GPU需先反量化到FP16、位并行加速器又只支持单一精度，低位宽无法节省计算。该文提出算法-硬件协同设计的混合精度加速器FIGFLEX，采用移位-加基4的FP-INT乘法重构与INT3优化，并配合按通道组分配位宽、幂次二归一化的混合精度量化器。在LLaMA-2-7B上，3位和2位平均精度下WikiText-2困惑度分别为5.85和8.77，优于GPTQ、AWQ等，线性GEMM整芯片单位面积吞吐比AxCore和FIGLUT分别高1.56倍和1.42倍。

- **arXiv**: [2610.30687](https://arxiv.org/abs/2610.30687)
- **Authors**: Beenish Gul, Mahbod Afarin, Farhat Ahmed, Sumukh Pinge, Tsung-Han Lu, Tajana Rosing, Kevin Skadron
- **Subjects**: cs.AR
- **Tags**: Clustering, Hyperdimensional Computing
- **Summary**: 鸟枪蛋白质组学产生海量串联质谱数据，DBSCAN密度不稳定、HAC复杂度O(n²)且聚类质量差，而Louvain质量高但难以流式扩展。该文提出HDLouvain，将Louvain社区检测与超维计算的位并行相似度计算结合，对引导子集按母离子质量分桶建kNN图，用位多数捆绑将社区压缩为二值超向量，新谱通过GPU加速汉明距离查找增量分配。在五个PRIDE数据集上，α从0.3到0.7时加速4.5倍至1.65倍，模块度从0.75升至0.95以上且最多比全量重算低8%，Louvain阶段在LFR网络上NMI达0.86-0.93，而DBSCAN和HAC降至0.57。

<h3 id="5">[5] SnakeCharmer: Orchestrating Utility, Timeliness, and Placement in GPU Prefetching</h3>
- **arXiv**: [2610.30990](https://arxiv.org/abs/2610.30990)
- **Authors**: Yuhan Tang, Tiejun Li, Jianmin Zhang, An Hu, Guangyu Sun, Sheng Ma, Yiqun Lang, Hanqing Li, Siqing Fu
- **Subjects**: cs.AR
- **Tags**: Hardware Architecture, GPU Computing
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: GPU地址预测预取器即使预测准确也未必带来性能提升，因为预取是否值得发出、是否及时到达、数据是否被保留三者相互制约。该文提出统一的后端预取控制框架SnakeCharmer，将地址预测与预取实现分离，通过零值感知过滤控制效用、分层反馈驱动距离调优控制及时性、寄存器辅助预取缓冲控制放置位置。在A100模型上，相比Snake性能/能效提升12.8%/20.8%，相比APOGEE提升1.7%/3.2%，硬件开销适中。

<h3 id="6">[6] Ray-by-Ray: Fine-Grained Resource Management for GPU Ray Tracing Units</h3>
- **arXiv**: [2610.31630](https://arxiv.org/abs/2610.31630)
- **Authors**: Junrui Pan, Cesar Avalos Baddouh, Kai Ze Ee, Timothy G. Rogers
- **Subjects**: cs.AR
- **Tags**: Hardware Architecture, GPU Computing
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture
- **Summary**: GPU光线追踪单元中每条光线独立推进，与SIMT执行模型存在粒度失配，导致控制与数据发散、片上缓冲资源管理低效。该文提出Ray-by-Ray，将片上缓冲分解到单条光线粒度，并引入轻量管理结构，使更多warp可并行运行而无需增加缓冲容量，从而提升RT单元利用率和内存级并行。实验表明平均性能提升1.91倍，面积开销仅0.19%。

<h3 id="7">[7] ARES: Adaptive Reasoning-Effort Steering for PPA- and Cost-Aware RTL Optimization with LLM Agents</h3>
- **arXiv**: [2607.27879](https://arxiv.org/abs/2607.27879) (replaced)
- **Authors**: Stef Cuyckens, Mihaela Jivanescu, Jun Yin, Chao Fang, Marian Verhelst
- **Subjects**: cs.AR; cs.AI
- **Tags**: LLM for EDA, LLM Agent
- **Summary**: LLM智能体优化RTL的PPA时每次调用都有美元成本，但已有工作只报告质量不报告归一化成本，且固定每次调用的推理强度。该文提出Ares，引入与FoM并列报告的每次调用归一化美元成本，发现精心设计的长期记忆相比简单拼接并无可靠增益，转而用耐心计数器在低推理强度停滞时才升级到更深推理。在三个未见测试设计上，该策略在同等归一化成本下将FoM降低22-28%（Opus 4.6）和18-34%（GPT-5.5），平均弥合LLM草拟MAC单元到手工优化版本差距的91%，并以35%成本达到比Dr. RTL低5%的FoM。

- **Subjects**: cs.AR; cs.DC
- **Tags**: Scheduling, Reinforcement Learning
- **Venue**: 34th International Conference on Real-Time Networks and Systems (RTNS 2026)
- **Summary**: 异构多加速器系统需同时执行硬实时与软实时QoS感知的DNN推理，现有调度难以兼顾。该文提出在线强化学习调度器与确定性运行时安全层结合的框架，RL联合选择子任务优先级与加速器分配，运行时认证保证硬实时截止期独立于学习策略得到满足，并引入基于机器切分的可调度性保持前缀替换准则。实验表明该框架在保持硬实时可调度性的同时，相比先进调度方法提升了QoS截止期满足率、客户端服务质量和加速器利用率。

<h3 id="9">[9] PAGE404: Breaking GPU Isolation Through Hardware-assisted Page Migration</h3>
- **arXiv**: [2610.20962](https://arxiv.org/abs/2610.20962) (replaced)
- **Authors**: Ravan Nazaraliyev, Yicheng Zhang, Nael Abu-Ghazaleh
- **Subjects**: cs.CR; cs.AR
- **Tags**: Hardware Security, Side-Channel Analysis
- **Venue**: 48th IEEE Symposium on Security and Privacy (S&P 2027)
- **Summary**: 该论文研究NVIDIA Grace Hopper (GH200)超级芯片中硬件辅助页面迁移机制的安全问题，指出其访问计数器共享结构和UVM驱动迁移中断处理流程存在两个侧信道漏洞。作者构建了基于驱逐和迁移延迟的隐蔽信道，在MIG分区之间分别达到约8500和8100比特/秒的传输速率，并能跨不同LLM和CPU SPEC2017基准指纹识别推理工作负载、高精度估计LLM推理的提示长度。这些结果揭示了硬件管理异构内存系统的安全缺口，并对当前MIG多租户GPU部署的隔离保证提出质疑。
