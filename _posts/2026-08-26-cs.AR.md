<h3 id="1">[1] Transformer Accelerator (TFA): A Macro-Op INT8 Hardware Chip for Transformer Inference and Machine Translation</h3>
- **arXiv**: [2608.23582](https://arxiv.org/abs/2608.23582)
- **Authors**: Shashank
- **Subjects**: cs.AR; cs.CL; cs.LG
- **Tags**: Hardware Acceleration, Transformer Architecture, Machine Translation
- **Summary**: 问题: Transformer推理在硬件加速方面面临INT8精度和可综合硬件实现的挑战。方法: 提出TFA，一种可综合、可参数化的INT8内存到内存引擎，通过宏操作描述符实现矩阵乘法、softmax等操作，并采用输出驻留乘累加阵列和ping-pong缓冲以重叠DMA与计算。结果: 在25项测试和34次约束随机运行中实现零失配、100%功能覆盖率与94.96%代码覆盖率；比22线程CPU快约20倍，并预计将每token能耗降低约1000倍。

<h3 id="2">[2] Squeezing the Cache, Preserving the Truth: Monotonic Equipotential Allocation with Geodesia-KV</h3>
- **arXiv**: [2608.23599](https://arxiv.org/abs/2608.23599)
- **Authors**: Vincenzo Dentamaro, Pancrazio Auteri, Giuseppe Pirlo
- **Subjects**: cs.AR; cs.CL
- **Tags**: KV Cache Management, LLM Inference, Memory Efficiency
- **Code**: [code](https://github.com/geodesia-ai/geodesia-kv)
- **Summary**: 问题: 现有KV缓存压缩评估混淆驻留比特与读取带宽，且受分块teacher-forcing伪影影响。方法: 提出Geodesia-KV，一种免训练的KV缓存策略家族，基于单调块级精度分配、精确率失真残差和查询稀疏读取。结果: 在WikiText-2 16k上下文下，5比特工作点在更低比特率下优于KIVI-4；在PG-19上将驻留/读取比特率降至9.83/1.95比特；在单张16GB GPU上实现1M token上下文生成，峰值VRAM节省71.7%。

- **Authors**: Sathishkumar Sivashanmugam
- **Subjects**: cs.AR; cs.AI
- **Tags**: KV Cache, LLM Serving, Memory Efficiency
- **Summary**: 问题: LLM服务引擎为最坏情况prefill预留给KV缓存，导致解码阶段该保留区闲置却无法回收。方法: 提出弹性KV缓存，利用调度器的前瞻视野在解码时将保留区借给KV池、prefill前归还，基于CUDA虚拟内存路径实现。结果: 解提交和重提交分别只需几毫秒和几十毫秒；但实验表明收益有限：不同chunk size下TTFT中位数仅差约1%，降低max_num_batched_tokens可回收更多KV。
