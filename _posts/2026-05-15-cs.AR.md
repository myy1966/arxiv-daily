## 跨领域投稿 (4)

<h3 id="1">[1] Evolving Layer-Specific Scalar Functions for Hardware-Aware Transformer Adaptation</h3>
- **arXiv**: [2605.14047](https://arxiv.org/abs/2605.14047) (cross-listed)
- **Authors**: Kieran Carrigg, Sigur de Vries, Amirhossein Sadough, Marcel van Gerven
- **Subjects**: cs.CV; cs.AR
- **Tags**: Vision Transformer, Edge Computing, Hardware Acceleration
- **Summary**: 本文提出了一种基于遗传编程的硬件感知框架，用于从预训练权重直接演化出异构的、层特定的标量函数来替代Vision Transformer中的层归一化。该方法无需从头重新训练模型，在20个epoch内恢复了84.25%的Top-1 ImageNet-1K准确率，同时消除了全局归约瓶颈，为ViT在边缘加速器上的高效部署提供了有利权衡。

<h3 id="2">[2] Time Domain Near Memory Computing Engine</h3>
- **arXiv**: [2605.14162](https://arxiv.org/abs/2605.14162) (cross-listed)
- **Authors**: Sarthak Antal, Steve Enosh
- **Subjects**: cs.ET; cs.AR; eess.SY
- **Tags**: Near-Data Processing, Energy Efficiency, Hardware Architecture
- **Summary**: 本文提出了一种用于低精度乘累加(MAC)操作的时域近存计算架构，通过电流导向DAC转换存储在SRAM中的数字权重位，并使用N脉冲生成器编码数字输入向量，在时域中执行乘法运算。该原型在1V电源下实现40MHz工作频率和7.62 TOPS/W的能效，在数字可扩展性和模拟能效之间取得了平衡。

<h3 id="3">[3] A Hardware-Aware, Per-Layer Methodology for Post-Training Quantization of Large Language Models</h3>
- **arXiv**: [2605.14929](https://arxiv.org/abs/2605.14929) (cross-listed)
- **Authors**: Earl Killian
- **Subjects**: cs.LG; cs.AR
- **Tags**: Quantization, Model Compression, LLM Inference
- **Summary**: 本文提出了Scaled Outer Product (SOP)方法，一种针对大语言模型权重的训练后量化技术，可在4.5-6位每权重的硬件上实现近乎无损的保真度。该方法结合了层特定的码本搜索、带符号的块级缩放和异常值校正，在比FP8基线低1.5 bpw存储成本的情况下实现了更低的权重重建误差。

<h3 id="4">[4] Accelerating State-Vector Quantum Simulation on Integrated GPUs via Cache Locality Optimization: A Cross-Architecture Evaluation</h3>
- **arXiv**: [2605.15098](https://arxiv.org/abs/2605.15098) (cross-listed)
- **Authors**: Gabriel Fernandes Thomaz, Jerusa Marchi, Eduarda Rodrigues Monteiro, Fernando Augusto Caletti de Barros, Evandro Chagas Ribeiro da Rosa
- **Subjects**: cs.AR; cs.DC; cs.PF
- **Tags**: Quantum Computing, GPU Computing, Cache Management
- **Summary**: 本文提出了一种面向集成GPU的供应商无关的量子电路仿真方法，通过状态分区优化重新组织量子状态向量以最大化末级缓存局部性。实验结果表明，该优化成功缓解了较大量子比特规模下的性能下降，在28量子比特仿真中将Intel Core i5的GPU加速比从0.95x提升至1.89x，Apple M1 Pro从3.71x提升至5.88x。

<h3 id="5">[5] Cerberus: Cross-Layer ECC Co-Design for Robust and Efficient Memory Protection</h3>
- **arXiv**: [2605.02220](https://arxiv.org/abs/2605.02220) (replaced)
- **Authors**: Junhwan Kim, Seunghyun Kim, Yesin Ryu, Saeid Gorgin, Jungrae Kim
- **Subjects**: cs.AR
- **Tags**: Fault Tolerance, Hardware Reliability, Memory Architecture
- **Venue**: ISCA 2026
- **Summary**: 本文提出了Cerberus，一种跨层ECC协同设计方案，通过Encode-Once, Decode-Many架构统一了设备、链路和系统层的内存保护。该方法联合设计互补的奇偶校验和伴随式结构，在减少冗余开销的同时提高了对集群和外围故障的恢复能力，为下一代内存系统提供了协调的跨层保护方案。

<h3 id="6">[6] TLX: Hardware-Native, Evolvable MIMW GPU Compiler for Large-scale Production Environments</h3>
- **arXiv**: [2605.10905](https://arxiv.org/abs/2605.10905) (replaced)
- **Authors**: Yue Guan, Hongtao Yu, Peng Chen, Daohang Shi, Karthik Manivannan, Nicholas J Riasanovsky, Manman Ren, Lei Wang, Shane Nay, Partha Kanuparthy, Zaifeng Pan, Zhengding Hu, Yufei Ding
- **Subjects**: cs.AR
- **Tags**: GPU Computing, Compiler Optimization, Hardware-Software Co-design
- **Code**: [code](https://github.com/facebookexperimental/triton)
- **Summary**: 本文提出了TLX (Triton Low-level Language Extensions)，一种基于MIMW (Multi-Instruction, Multi-Warp)的GPU编译器，在warp-group粒度上表达编排操作同时保留Triton高效的块编程模型。TLX支持有限开发工作量下的深度定制，已部署于大规模训练和推理生产系统中。

<h3 id="7">[7] Non-Monotonic Latency in Apple MPS Decoding: KV Cache Interactions and Execution Regimes</h3>
- **arXiv**: [2605.08913](https://arxiv.org/abs/2605.08913) (replaced)
- **Authors**: Willy Fitra Hendria
- **Subjects**: cs.LG; cs.AR; cs.CL; cs.PF
- **Tags**: KV Cache, LLM Inference
- **Summary**: 本文发现了Apple MPS后端在Transformer解码过程中存在非单调延迟行为，在特定解码配置区间内延迟激增高达21倍。研究表明KV缓存与这些病态执行机制存在强交互，强调了硬件感知评估对于长上下文推理的重要性。
