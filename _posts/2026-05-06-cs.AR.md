<h3 id="1">[1] Design and Implementation of BNN-Based Object Detection on FPGA</h3>
- **arXiv**: [2605.03396](https://arxiv.org/abs/2605.03396)
- **Authors**: Xuyu Zhao, Yunpeng Wu, Mengyuan Zhu, Haoyu Huang, Xiaoyu Xu, Yanjing Li, Gaolong Zhang, Baochang Zhang
- **Subjects**: cs.AR
- **Tags**: Object Detection, FPGA, Model Compression
- **Summary**: 本文在低成本FPGA上实现了基于二值神经网络(BNN)的YOLOv3-tiny目标检测器，主要卷积层采用1位权重和8位激活值。硬件采用Verilog RTL实现，在VOC数据集上达到39.6% mAP50，RTL仿真与ONNX模型的相关系数达0.999964。

<h3 id="2">[2] SPEC CPU2026: Characterization, Representativeness, and Cross-Suite Comparison</h3>
- **arXiv**: [2605.03713](https://arxiv.org/abs/2605.03713)
- **Authors**: Ruihao Li, Andrew Jacob, Neeraja J. Yadwadkar, Lizy K. John
- **Subjects**: cs.AR; cs.PF
- **Tags**: Benchmark, Hardware Architecture, Performance Modeling
- **Summary**: 本文首次对SPEC CPU2026基准测试套件进行了全面表征，覆盖Intel、AMD、Ampere和Nvidia等九个平台。研究发现SPEC CPU2026相比CPU2017增加了指令量和内存占用，并识别出每组4-5个工作负载的紧凑子集可保留96.4-99.9%的完整套件行为。

- **Tags**: Quantum Error Correction, FPGA, Quantum Computing

<h3 id="4">[4] LIPPEN: A Lightweight In-Place Pointer Encryption Architecture for Pointer Integrity</h3>

- **Tags**: Hardware Security, RISC-V, FPGA
- **Venue**: ISCA 2026
