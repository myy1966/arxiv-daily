<h3 id="1">[1] HEMERA: A Heterogeneous Memory-Centric Accelerator with Recursive Dataflow for Edge-Constrained State-Space-Duality Models Inference</h3>
- **arXiv**: [2607.22022](https://arxiv.org/abs/2607.22022)
- **Authors**: Hao Ding, Ling Liang, Ruitong Qiao, Dongxue Zhao, Xiantong Qiu, Jinshan Li, Meng Li, Lei Jin, Zhiliang Xia, Zongliang Huo, Zongwei Wang, Yimao Cai
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Hardware Accelerator, Memory Architecture
- **Venue**: ICCAD 2026
- **Summary**: 针对结构化状态空间模型（如Mamba）推断中二次中间物化、不规则数据移动等开销问题，提出HEMERA异构内存中心加速器，将矩阵形式SSD计算重构成流式递归数据流，避免二次存储，并采用内存计算单元和专用流引擎的异构执行。在130M至2.8B参数模型上，相比A100平均延迟加速1.4–3.6倍，能效提升12.2–27.0倍，长序列推断中SSD相关执行时间占比降至14.12%。

<h3 id="2">[2] Sparse by Command: Task-Conditional Compute Skipping for Multi-Task Inference Accelerators</h3>
- **arXiv**: [2607.22038](https://arxiv.org/abs/2607.22038)
- **Authors**: Afzal Ahmad, Gaoyu Mao, Shoubo Hu, Hui-Ling Zhen, Mingxuan Yuan, Xinyu Chen, Wei Zhang
- **Subjects**: cs.AR; cs.AI
- **Tags**: Multi-Task Learning, Hardware Accelerator, Sparse Inference
- **Venue**: IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 针对多任务推断中共享骨干网络执行相同计算浪费资源的问题，提出软硬件协同方法，使用轻量门控网络根据任务输入预测每瓦片二进制掩码，跳过不必要计算。在FPGA原型上，任务条件稀疏性减少66–76%的FLOPs，延迟降低51–59%，能耗从263mJ降至108–128mJ。

<h3 id="3">[3] HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding</h3>
- **arXiv**: [2607.22389](https://arxiv.org/abs/2607.22389)
- **Authors**: Chao Fang, Jun Yin, Man Shi, Marian Verhelst
- **Subjects**: cs.AR; cs.AI; cs.LG
- **Tags**: KV Cache, LLM Inference, Hardware Accelerator
- **Venue**: IEEE Transactions on Circuits and Systems I: Regular Papers (TCAS-I)
- **Summary**: 针对长上下文LLM解码中KV缓存持续增长的内存瓶颈，提出HiKV算法硬件协同设计，通过两级重要性感知压缩（令牌级淘汰和元素级加载），并设计可重构重要性排序器加速器。在代表性LLM上，相比原始KV缓存实现最高7.95倍加速和90%能耗降低，精度损失小于1%，外部内存访问额外减少1.82–4.87倍。

## 跨领域投稿 (2)

<h3 id="4">[4] RED-PIM: Reducing Data Movement for Transformers using Processing-in-Memory</h3>
- **arXiv**: [2607.21731](https://arxiv.org/abs/2607.21731) (cross-listed)
- **Authors**: Zahra Yousefijamarani, Alaa Alameldeen
- **Subjects**: cs.LG; cs.AR
- **Tags**: Processing-in-Memory, Transformer Architecture, Hardware Accelerator
- **Summary**: 针对Transformer注意力计算中数据移动量大的问题，提出RED-PIM算法架构协同设计，通过重新组织矩阵运算和优化数据传输，将跨bank数据移动从O(N²)降至O(N)，注意力矩阵大小从N×N缩至d×d。相比基线PIM实现，推断时间减少16.05%–99.99%（几何平均66.42%），长文档性能提升99.60%，短文档提升13.44%，同时保持或提升精度。

- **Authors**: Jinhyeok Kim, Yejoon Lee, Jaeyoung Do
- **Subjects**: cs.DC; cs.AI; cs.AR; cs.LG
- **Tags**: LLM Inference, Model Compression, Sparse Inference
- **Venue**: Proceedings of the VLDB Endowment (PVLDB) 2026
- **Code**: [code](https://github.com/AIDASLab/SPDP)

- **Authors**: Aziz Alajmi, Hoeseok Yang
- **Subjects**: cs.AR; cs.CR
- **Tags**: Rowhammer, Hardware Security, Memory Architecture
