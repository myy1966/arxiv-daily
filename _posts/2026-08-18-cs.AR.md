<h3 id="1">[1] Concurrency Response of Plain Global Loads on the NVIDIA H100</h3>
- **arXiv**: [2608.15764](https://arxiv.org/abs/2608.15764)
- **Authors**: Somashekar Manjunath, Rahul Ramachandra M
- **Subjects**: cs.AR; cs.PF
- **Tags**: GPU Computing, Memory Architecture
- **Summary**: 该论文针对NVIDIA H100上普通全局加载（plain loads）的并发响应问题，采用基于Little's Law的clean-room微基准测试，测量LDG带宽随每线程加载数K的变化。结果表明带宽在K~2时达到峰值，随后在K=2至K=8间下降约35%（两个芯片一致），同时DRAM流量基本不变而L2流量上升，且该现象与分配大小无关。

<h3 id="2">[2] Beyond Binary Priorities: Multi-Tier SLA Scheduling for Large Language Model Serving</h3>
- **arXiv**: [2608.16336](https://arxiv.org/abs/2608.16336)
- **Authors**: Anders Vestrum, Arya Raeesi, Hanna Roed
- **Subjects**: cs.AR; cs.DC; cs.LG
- **Tags**: LLM Serving, LLM Inference, Scheduling
- **Summary**: 该论文针对LLM服务调度中优先级模型仅支持两级、难以表达生产环境多级SLA的问题，将Llumnix扩展为任意多级优先级调度，并实现分层余量、层级感知调度和迁移管线，在Vidur模拟器中评估。实验显示四级优先级在成本效益上最优，相对INFaaS在prefill平均加速8.3x、端到端P99加速3.1x，成本-延迟改善46-68%，并在10级优先级下保持稳定。

<h3 id="6">[6] NPU Offloading of a Frozen Visual Encoder for Robot Policy Training</h3>

- **Subjects**: cs.RO; cs.AR; cs.LG
- **Tags**: Robotics, Heterogeneous Computing, Energy Efficiency
- **Summary**: 该论文针对机器人策略训练中冻结视觉编码器仍占用GPU算力的问题，提出将INT8编码器异步卸载到NPU、GPU只训练动作模块的管线。结果显示每样本能量降低17.1%（L1）至27.9%（L4），但训练时间增加15.2%-37.7%，显存占用降低约20%，策略成功率下降0.44-1.89个百分点，表明NPU卸载可节能但以时间和性能为代价。

<h3 id="7">[7] TIDE: An FPGA quantum-control processor for deterministic adaptive execution with guarded runtime program revision</h3>

- **Authors**: Xiaoqin Luo, Jiayun Song, Xiaolu Su
- **Subjects**: cs.AR
- **Tags**: Quantum Computing, FPGA, Hardware Architecture
- **Summary**: 该论文针对量子控制程序需要运行时修订未来操作但又不影响已确定时序的问题，提出TIDE（Time-Deterministic and Instruction-Dynamic Execution）FPGA量子控制处理器，提供DIPU和DISO两种更新路径并隔离已提交事件。实现中控制核250 MHz、时序域425 MHz，所有描述子均在计划时间前提交，最小DIPU余量为4个周期，DISO事务可完整执行修订序列。
