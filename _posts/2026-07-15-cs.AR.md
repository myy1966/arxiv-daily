<h3 id="1">[1] FPGA-Based Mini X-Ray Detector Front-End</h3>
- **arXiv**: [2607.12126](https://arxiv.org/abs/2607.12126)
- **Authors**: Kris Paetow, D.G. Perera
- **Subjects**: cs.AR
- **Tags**: FPGA, Medical AI
- **Summary**: 问题：医疗影像系统需要可靠的前端电子设备，但FPGA应用在简单演示中缺乏具体方案。方法：提出基于FPGA的微型X射线探测器前端演示。结果：实现了可预测时序和低延迟的数据采集与处理。

<h3 id="2">[2] ORRAM: An OpenROAD-Integrated RAM Generator Using Standard Cells</h3>
- **arXiv**: [2607.12244](https://arxiv.org/abs/2607.12244)
- **Authors**: Brayden Louie, Thinh P. Nguyen, Matt Liberty, Austin Rovinski
- **Subjects**: cs.AR
- **Tags**: Memory Architecture, EDA
- **Venue**: 2026 Open-Source Computer Architecture Research Workshop (OSCAR)
- **Summary**: 问题：在ASIC设计流程中，从RTL推断存储器会引入大量触发器，降低性能，而第三方存储器编译器通常依赖特定PDK。方法：提出ORRAM，一个基于标准单元的存储器生成器，集成在OpenROAD内，无需自定义位单元或外部工具。结果：在SkyWater 130nm上匹配历史DFFRAM的位密度，并支持更多功能。

<h3 id="3">[3] Emulated Integrity Replica: Enabling Self-Healing on FPGA SoCs via Hierarchical Twins</h3>
- **arXiv**: [2607.12298](https://arxiv.org/abs/2607.12298)
- **Authors**: Arsalan Ali Malik, Ali Suvizi, Guru Venkataramani, Aydin Aysu
- **Subjects**: cs.AR; cs.CY
- **Tags**: Fault Tolerance, FPGA, Hardware Reliability
- **Summary**: 问题：FPGA SoC上CNN推理的容错方案（如DMR/TMR）资源开销大，软件方法延迟高。方法：提出EIR，一种层次化数字孪生框架，利用PS空闲周期运行粗粒度和细粒度模型进行故障检测与恢复。结果：相对于DMR基线，在降低能耗和面积的条件下实现了高故障覆盖率。

<h3 id="4">[4] ArchSim: Computer Architecture Simulation as a Service</h3>
- **arXiv**: [2607.12359](https://arxiv.org/abs/2607.12359)
- **Authors**: Sabila Al Jannat, Wenhan Lyu, Le Khanh Trinh Mai, Huizhi Zhao, Zhuoyan Zheng, Katherine E. Isaacs, Yifan Sun
- **Subjects**: cs.AR
- **Tags**: Hardware Simulation, GPU Computing
- **Summary**: 问题：计算机体系结构仿真研究因配置隐式编码而难以扩展和复现。方法：提出ArchSim，通过声明式拓扑图生成仿真代码，使用无状态执行器自动调度任务。结果：在96个GPU配置的仿真矩阵中，中位内核时间误差0.18%，每仿真开销仅1.6秒。

<h3 id="10">[10] Dynamic Rowhammer Threshold Management:Temperature-Aware Threshold Degradation for In-DRAM Defenses</h3>

- **Authors**: Aziz Alajmi, Hoeseok Yang
- **Subjects**: cs.AR; cs.CR
- **Tags**: DRAM, RowHammer, Hardware Security
- **Venue**: Sixth Workshop on DRAM Security (DRAMSec 2026)
- **Summary**: 问题：DRAM Rowhammer防御阈值在制造时固定，但实际阈值随温度变化。方法：提出动态Rowhammer阈值管理，基于线性温度模型和防护带，调整SALT-C、PRAC和TRR的阈值。结果：PRAC在85°C时违规数降至0，SALT-C违规数从10降至2（动态）再到0（自举）。

- **Subjects**: cs.CV; cs.AR; cs.DC; cs.LG; cs.SE
- **Tags**: Object Detection, Edge Computing, Benchmark, Model Evaluation
- **Summary**: 问题：不同目标检测模型在异构边缘设备及场景复杂度下的表现缺乏系统评估。方法：在多种边缘设备上评测YOLOv8、EfficientDet Lite和SSD，考虑精度、延迟和能耗。结果：SSD MobileNet V1延迟最低但精度最低，YOLOv8 Medium精度最高；Orin Nano平衡最佳；场景复杂度增加时精度差距扩大。
