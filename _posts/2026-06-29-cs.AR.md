## 新投稿 (5)

<h3 id="1">[1] MultModLM: A multi-modal benchmark for Large-Language Model based hardware schematic generation</h3>
- **arXiv**: [2606.27666](https://arxiv.org/abs/2606.27666)
- **Authors**: Dhruv Kulkarni, Sai Manoj Pudukotai Dinkarrao
- **Subjects**: cs.AR
- **Tags**: RTL Generation, LLM Evaluation
- **Summary**: 针对多模态LLM在硬件原理图生成中的缺失，提出一个包含99个RTL模块的基准测试和多阶段评估框架。实验表明模型能生成可解释的原理图但功能正确性有限，且LLM作为评估者与人类评分几乎不一致，揭示了多模态硬件输出可靠评估的挑战。

<h3 id="2">[2] SEADA: An efficient methodology for optimizing mixed-precision DNNs on multi-precision spatial architectures</h3>
- **arXiv**: [2606.27884](https://arxiv.org/abs/2606.27884)
- **Authors**: Leandro Fiorin, Marco Ronzani, Cristina Silvano
- **Subjects**: cs.AR; cs.AI
- **Tags**: Mixed Precision Training, DNN Deployment, Design Space Exploration
- **Summary**: 针对混合精度DNN在多精度空间架构上的高效映射问题，提出SEADA方法，包括系统级成本模型、快速映射工具和基于比特级熵的精度选择。通过实验证明了其在设计空间探索中的效率。

<h3 id="3">[3] Co-Optimization of Analog Kolmogorov-Arnold Networks for Low-Power Function Approximation in Flexible Electronics</h3>
- **arXiv**: [2606.27892](https://arxiv.org/abs/2606.27892)
- **Authors**: Paula Carolina Lozano Duarte, Georgios Zervakis, Mehdi Tahoori, Sani Nassif
- **Subjects**: cs.AR; cs.ET; cs.NE
- **Tags**: Kolmogorov-Arnold Network, Hardware-Software Co-design, Low Power
- **Venue**: IEEE Journal On Emerging and Selected Topics In Circuits and Systems
- **Summary**: 针对柔性电子中低功耗模拟函数逼近的需求，提出模拟KAN网络，通过硬件-软件协同优化和剪枝，在多个基准上实现了高达55%面积和50%功耗的节省，同时保持逼近精度。

<h3 id="4">[4] Phase Matters: Characterizing Heterogeneous Vision-Language Inference on a Mobile SoC</h3>
- **arXiv**: [2606.27906](https://arxiv.org/abs/2606.27906)
- **Authors**: Aryama V Murthy, Yashas N Kotre, Prathmesh Sharma, Pragya Mishra, Sanjith Ganapathi, Priyesh Shukla
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Vision-Language Model, Mobile AI
- **Venue**: MobiSys Workshop '26
- **Summary**: 针对VLM流水线在异构后端上的映射缺乏阶段级指导，对骁龙8 Elite进行硬件在环表征，发现NPU执行阶段依赖性，预填加速1.64倍，解码仅1.18倍，视觉编码器加速20-45倍，并降低了10.47°C温度和2.52倍能耗。

<h3 id="5">[5] Agentic Hardware Design as Repository-Level Code Evolution</h3>
- **arXiv**: [2606.28279](https://arxiv.org/abs/2606.28279)
- **Authors**: Cunxi Yu, Chenhui Deng, Nathaniel Pinckney, Brucek Khailany
- **Subjects**: cs.AR; cs.AI
- **Tags**: LLM Agent, RTL Generation, EDA
- **Summary**: 将硬件设计视为仓库级代码演化的自演化智能体框架，通过Markdown编译的执行环境实现免手动智能体循环。在多个基准测试上达到100%完成率，但指出这些基准是受限的代理，开放研究挑战仍存。
