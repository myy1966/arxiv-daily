## 新投稿 (4)

<h3 id="1">[1] Exploring High-Bandwidth Flash for Modern LLM Inference: Opportunities and Challenges</h3>
- **arXiv**: [2608.13868](https://arxiv.org/abs/2608.13868)
- **Authors**: Dowon Son, Yonggon Park, Hyunuk Cho, Hyungkyu Ham, Onur Mutlu, Sungjin Lee, Gwangsun Kim, Jisung Park
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Memory Architecture
- **Summary**: 本文针对高带宽闪存(HBF)在LLM推理中的应用效益与挑战尚未被系统研究的问题，提出对HBF作为GPU主内存组件的LLM服务系统进行多配置分析。结果显示HBF能显著提高批处理大小、吞吐量和灵活性，并降低GPU最低需求，但依赖HBM级读取带宽和持久性改进。

<h3 id="2">[2] MoE Expert Execution in Disaggregated LLM Serving with a High-Bandwidth ReRAM Near-Memory Architecture</h3>
- **arXiv**: [2608.13962](https://arxiv.org/abs/2608.13962)
- **Authors**: Kunming Shao, Ming Zeng, Xin Yuan, Binbin Liao, Yangming Zhang, Wei Wang, Tim Kwang-Ting Cheng, Chi-Ying Tsui
- **Subjects**: cs.AR
- **Tags**: Mixture-of-Experts, ReRAM, Near-Data Processing
- **Summary**: 本文针对MoE模型在LLM服务中专家权重常驻与稀疏路由导致的带宽利用低和资源闲置问题，提出一种ReRAM近内存架构，通过核心本地多播池化、共激活感知放置和负载感知获取恢复占用率。在Qwen3.5等模型上，侧4池化将占用率从0.328提升至0.519，每token FFN池延迟比H20降低9.5倍，权移动能耗降低20倍。

<h3 id="3">[3] Experimental Study on System-Level Performance Impact of Read Disturbance in Modern SSDs</h3>
- **arXiv**: [2608.14073](https://arxiv.org/abs/2608.14073)
- **Authors**: Yonggon Park, Hyunuk Cho, Onur Mutlu, Sungjin Lee, Jisung Park
- **Subjects**: cs.AR
- **Tags**: Storage Systems, Hardware Reliability
- **Venue**: SIGMETRICS 2026
- **Summary**: 本文针对现代SSD中读干扰对系统级性能的影响缺乏研究的问题，对10家厂商的15款NVMe SSD进行了实验研究。研究分析了多种工作负载下的性能影响，并展示了一种利用读干扰的SSD性能攻击。基于实验总结出16项观察、7条经验教训和6个未来改进方向。

<h3 id="4">[4] Beyond Capacity: Scalable MoE LLM Inference via High-Bandwidth Flash with Direct GPU and HBM Paths</h3>
- **arXiv**: [2608.14333](https://arxiv.org/abs/2608.14333)
- **Authors**: Seeyeon Kim, Juhyeong Jin, Joo-Young Kim
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Mixture-of-Experts, Memory Architecture
- **Summary**: 本文针对MoE大模型权重超出HBM容量和成本的问题，探索一种同时利用直接GPU-HBF路径和HBF-HBM-GPU中继路径的HBF组织结构。通过整专家分配、并发传输、早期专家确定和权重与KV缓存分离管理，在代表性工作负载上比仅经HBM交付的方案实现1.94倍吞吐量和1.90倍端到端加速。

<h3 id="6">[6] Characterizing the Variance Envelope: A Multi-Dimensional Analysis of Spectre Telemetry Across Architectures and Workloads</h3>
- **arXiv**: [2608.13920](https://arxiv.org/abs/2608.13920) (cross-listed)
- **Authors**: Jaya Keshava Chandra Kotha, Jean-Luc Gaudiot
- **Subjects**: cs.CR; cs.AR
- **Tags**: Side-Channel Attack, Hardware Security
- **Summary**: 本文针对静态模型在真实环境中检测Spectre攻击失效的问题，表征了跨Intel、ARM、AMD架构的"方差包络"。通过涵盖三种攻击变体、四种节奏模式和四种背景噪声的实验矩阵，证明HPC签名高度脆弱且易受环境扭曲，并暴露了AMD Jaguar上Prime+Probe攻击的硬件级失败，表明需要架构感知的自适应监控。

<h3 id="7">[7] The Quartic Hessian Conjecture in Dimension Four</h3>
- **arXiv**: [2608.14217](https://arxiv.org/abs/2608.14217) (cross-listed)
- **Authors**: Zixiang Ni
- **Subjects**: math.AG; cs.AR
- **Tags**: Mathematical Reasoning
- **Summary**: 本文针对Hessian猜想在四维情况下仍开放的问题，证明了四变量四次情形。通过将顶部齐次部分分为三种类型，并利用Schur补、各向同性锥秩分析等方法，最终证明所有常数Hessian多项式均存在多项式梯度逆。

- **Subjects**: cs.AR
