<h3 id="1">[1] SPEAR: A System for Post-Quantization Error-Adaptive Recovery Enabling Efficient Low-Bit LLM Serving</h3>
- **arXiv**: [2606.11244](https://arxiv.org/abs/2606.11244)
- **Authors**: Hongyuan Liu, Yawei Li, Zhiqiang Que, Qinli Yang, Junming Shao, Guosheng Hu
- **Subjects**: cs.AR; cs.AI
- **Tags**: LLM Inference, Quantization, Model Compression
- **Summary**: 该论文针对LLM低比特量化中量化误差高度依赖输入且跨token变化显著，而现有补偿方法静态处理导致简单token过度校正、困难token校正不足的问题。提出了SPEAR系统，通过CKA引导的熵感知诊断识别误差敏感层，引入轻量级误差补偿器(EC)和逐token门控机制，并采用自适应内核融合调度策略实现高效部署。实验表明，SPEAR在W4量化设置下恢复了56-75%的困惑度差距，仅增加不到1%的内存开销，延迟与主流4比特部署相当。

<h3 id="2">[2] A Fast Locality Simulator for GEMM Design-Space Exploration on Multi-Chiplet GPUs</h3>
- **arXiv**: [2606.11716](https://arxiv.org/abs/2606.11716)
- **Authors**: Euijun Chung, Hyesoon Kim
- **Subjects**: cs.AR
- **Tags**: GPU Computing, Hardware Architecture, LLM Inference
- **Summary**: 该论文针对多芯片GPU中GEMM算子的跨芯片远程HBM访问严重影响性能和能效，且最优数据放置策略难以确定的问题。提出了一个快速功能级局部性模拟器，建模CTA调度、每芯片L2缓存和本地/远程HBM访问，用于评估全尺寸LLM GEMM配置。实验发现远程流量在设计空间中变化高达90倍，通过AI代理优化发现2D块swizzle CTA遍历策略相比最优1D遍历可减少高达5.1倍的远程流量。

<h3 id="3">[3] Making Locality-aware GEMM Compatible with Page-Granularity Placement on Chiplet GPUs</h3>
- **arXiv**: [2606.11718](https://arxiv.org/abs/2606.11718)
- **Authors**: Euijun Chung, Jae Hyung Ju, Hyesoon Kim
- **Subjects**: cs.AR
- **Tags**: GPU Computing, Hardware Architecture, LLM Inference
- **Summary**: 该论文针对多芯片GPU中局部性感知数据放置与固定页粒度交错机制不兼容的问题，导致无法有效减少跨芯片远程HBM访问。提出了Chiplet-Contiguous Layout全局内存布局，将芯片本地数据连续存储，使局部性感知放置与页粒度放置兼容，无需修改操作系统或硬件。在Qwen 3 30B和Llama 3.1 70B的GEMM上，相比4KB交错平均减少远程HBM流量24.7倍和19.2倍，相比粗粒度局部性感知放置减少4.1倍和2.1倍。

<h3 id="4">[4] BenDi: An Energy-Efficient Quasi-Stochastic Systolic Architecture for Edge Bioelectronics</h3>

- **Authors**: Bochen Ye, Yihan Pan, Shady Agwa, Themis Prodromakis
- **Subjects**: cs.AR
- **Tags**: Edge Computing, Energy Efficiency, Medical AI
- **Venue**: International Conference on Application-specific Systems, Architectures and Processors (ASAP 2026)
- **Summary**: 该论文针对边缘生物电子设备资源受限环境下CNN模型部署困难的问题，传统AI硬件难以满足长期生物医学信号监测的计算需求。提出了BenDi准随机脉动阵列架构，采用低供电电压、Bent-Pyramid数据格式、DiP脉动数据流和硬件感知量化等多级优化策略。在22nm工艺下，0.5V电压100MHz时面积减少3.35倍，能效提升5倍，在MIT-BIH和Apnea-ECG基准上仅损失1%至3.3%的准确率。

<h3 id="6">[6] TileFuse: A Fused Mixed-Precision Kernel Library for Efficient Quantized LLM Inference on AMD NPUs</h3>
- **arXiv**: [2606.11357](https://arxiv.org/abs/2606.11357) (cross-listed)
- **Authors**: Wesley Pang, Gregory Hyegang Jun, Feiyang Liu, Deming Chen
- **Subjects**: cs.DC; cs.AI; cs.AR; cs.PF
- **Tags**: LLM Inference, Quantization, NPU
- **Summary**: 该论文针对边缘设备上LLM推理部署困难的问题，现有NPU软件栈不支持AWQ等主流量化格式，且底层控制受限。提出了TileFuse混合精度内核库，针对AMD XDNA2 NPU协同设计权重布局、元数据放置、混合精度微内核和阵列级数据流，将解包、反量化和GEMM/GEMV执行融合为单一内核流。相比全精度基线，GEMM性能提升121.6%，GEMV提升281%；端到端LLM实验中预填充延迟降低2.0倍，能耗降低64.6%。

<h3 id="7">[7] Partitioned Tags, Shared Data: Reconciling Strict Cache Isolation with Write-Shared Coherence</h3>
- **arXiv**: [2606.12259](https://arxiv.org/abs/2606.12259) (cross-listed)
- **Authors**: Kartik Ramkrishnan, Stephen McCamant, Antonia Zhai, Pen Chung Yew
- **Subjects**: cs.CR; cs.AR
- **Tags**: Hardware Security, Cache Management, Side-Channel Attack
- **Summary**: 该论文针对缓存分区作为防御驱逐式缓存侧信道的强结构防御手段，在共享操作系统环境中长期存在写共享一致性崩溃的设计问题。提出了SCP(安全一致性分区)方案，仅分区标签而共享单一数据池，通过调整数据池大小防止容量驱动的跨分区驱逐，并采用时序混淆和阈值触发的LLC写入路由机制。实验表明SCP可缓解Prime+Probe、Flush+Reload和共享可写行攻击，攻击结果不优于随机猜测，硬件开销仅+2.8% LLC SRAM，性能与DAWG相差0.3% IPC以内。

<h3 id="8">[8] Characterizing the Impact of NVFP4 Quantization for Low-Power Edge AI Deployment</h3>
- **arXiv**: [2606.06527](https://arxiv.org/abs/2606.06527) (replaced)
- **Authors**: Ovishake Sen, Venkata Nithin Kamineni, Daniel Lobo, Swarup Bhunia, Rickard Ewetz, Baibhab Chatterjee
- **Subjects**: cs.AR; cs.LG
- **Tags**: Quantization, Edge Computing, Low Power
- **Summary**: 该论文针对边缘AI部署中神经网络推理需要在降低计算成本、内存流量、计算能耗和存储开销的同时保持可接受精度的问题。对NVFP4量化进行了消融研究，该格式使用4比特FP4数据、FP8块尺度和FP32张量尺度，系统分析了激活精度、权重精度、块大小缩放、重训练与模型精度之间的关系。实验表明块大小B=16提供实用的精度/存储权衡，NVFP4结合重训练可获得最佳精度，而传统FP4推理会导致紧凑模型精度崩溃。

<h3 id="9">[9] FOCUS: DLLMs Know How to Tame Their Compute Bound</h3>
- **arXiv**: [2601.23278](https://arxiv.org/abs/2601.23278) (replaced)
- **Authors**: Kaihua Liang, Xin Tan, An Zhong, Hong Xu, Marco Canini
- **Subjects**: cs.LG; cs.AR; cs.CL
- **Tags**: LLM Inference, Diffusion Language Model
- **Venue**: ICML 2026
- **Summary**: 该论文针对扩散大语言模型(DLLM)解码成本高的问题，发现其计算在token块上并行化，但每个扩散步骤只有少量token可解码，导致大部分计算浪费在不可解码token上。观察到注意力派生的token重要性与token解码概率强相关，提出了FOCUS推理系统，动态聚焦计算于可解码token并即时驱逐不可解码token，从而增加有效批大小并缓解计算限制。实验表明FOCUS在大批设置下相比生产级引擎LMDeploy实现高达3.52倍吞吐量提升，同时保持或改善生成质量。
