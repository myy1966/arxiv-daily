<h3 id="1">[1] EdgeXpert: An Edge Device for Memory-Efficient LLM Inference with Mixture-of-Experts and Speculative Decoding</h3>
- **arXiv**: [2608.05303](https://arxiv.org/abs/2608.05303)
- **Authors**: Sangwoo Ha, Hyunwoo Seo, Yurim Jo, Youngjin Moon, Hoi-Jun Yoo
- **Subjects**: cs.AR; cs.CL; cs.LG
- **Tags**: LLM Inference, Speculative Decoding, Mixture-of-Experts
- **Venue**: 59th IEEE/ACM International Symposium on Microarchitecture (MICRO 2026)
- **Summary**: 针对边缘设备上LLM推理中外部内存访问瓶颈以及推测解码与混合专家（MoE）结合时的不兼容问题，提出了软硬件协同设计的EdgeXpert加速器。该加速器在预填充阶段利用提示级专家复用，在解码阶段利用深度感知专家合并来减少内存访问。在Samsung 28nm工艺下，相比先前工作延迟降低最多56.3%，能耗降低44.1%，并保持接近基线的精度。

<h3 id="2">[2] PowerScope: ML-based Intra-Cycle Power Estimation</h3>
- **arXiv**: [2608.05339](https://arxiv.org/abs/2608.05339)
- **Authors**: Jayanth Balasubramanian, Sujay Pandit, Radha Vaidya, Anand Raghunathan
- **Subjects**: cs.AR
- **Tags**: Power Estimation
- **Summary**: 针对现有ML功耗估计仅覆盖平均或每周期功耗、无法满足亚时钟周期分辨率需求的空白，提出了首个基于ML的周期内功耗估计框架PowerScope，仅需RTL仿真轨迹即可推理。与商业门级后布局功耗工具相比，中位绝对百分比误差5.88%，平均9%，速度提高约80倍，并可用于预硅功耗侧信道评估。

<h3 id="3">[3] PLoRA: An NDP-Enhanced Pooled-Memory System for Cost-Efficient Multi-LoRA Serving</h3>
- **arXiv**: [2608.05483](https://arxiv.org/abs/2608.05483)
- **Authors**: Zhongkai Yu, Ohm Rishabh Venkatachalam, Zheng Wang, Yikai Li, Yichen Lin, Zihao Yu, Yuke Wang, Liu Liu, Xulong Tang, Shuyi Pei, Yangwook Kang, Yufei Ding
- **Subjects**: cs.AR; cs.DC
- **Tags**: LLM Serving, LoRA, Near-Data Processing
- **Summary**: 针对多LoRA服务中适配器经PCIe分阶段加载导致的存储和延迟瓶颈，提出了PLoRA，利用支持近数据处理（NDP）的池化内存系统，将适配器和KV缓存保留在池中，仅通过读-计算接口返回结果。在H100上服务1000个适配器时，平均解码延迟比S-LoRA低6.6倍，器件面积增加低于3.4%，吞吐在短上下文中饱和于32GB/s。

- **arXiv**: [2608.05638](https://arxiv.org/abs/2608.05638)
- **Authors**: Nathanael Ren
- **Subjects**: cs.AR; eess.SY
- **Tags**: Hardware-Software Co-design, Real-Time Systems
- **Summary**: 针对控制循环中传感器读取和周期性执行占用指令与周期的问题，通过将外设输入直接映射为架构寄存器状态并将PWM通道卸载至硬件，实现了零指令传感器读取。在自平衡自行车控制回路中，最坏情况循环从91周期降至43周期，相对20毫秒执行帧留有约7300倍至15000倍的裕量。

- **Subjects**: cs.PL; cs.AR
- **Tags**: Speculative Execution, Hardware-Software Co-design
