<h3 id="1">[1] FREESS: A Web-Based Educational Simulator for a RISC-V-Inspired Superscalar Processor with Tomasulo-Style Dynamic Scheduling</h3>

- **Authors**: Roberto Giorgi, Miquel Moretó Planas
- **Subjects**: cs.AR; cs.PF
- **Tags**: Hardware Simulation, RISC-V
- **Summary**: 现有RISC-V超标量处理器教学工具缺乏开源、交互式模拟环境。提出FREESS，一个基于Web的开源教学模拟器，支持Tomasulo动态调度，提供周期级视图和可调参数。该工具已用于高级计算机架构教学约十五年，并在GitHub上公开。

<h3 id="2">[2] Memory-Bound but Not Bandwidth-Limited: The Physical AI Inference Gap in Batch-1 LLM Decode</h3>
- **arXiv**: [2605.30571](https://arxiv.org/abs/2605.30571)
- **Authors**: Josef Chen
- **Subjects**: cs.AR; cs.AI; cs.DC; cs.PF; cs.RO
- **Tags**: LLM Inference, GPU Computing, Quantization
- **Summary**: 物理AI系统（如机器人）的单流批处理解码通常被认为是内存带宽受限，但实测显示带宽利用率低。通过测量多个GPU上的batch-1解码延迟，分析CUDA Graphs对延迟的影响。在H100上CUDA Graphs提升1.259倍，而L4仅提升1.028倍；量化路径未达到预期加速，GPTQ+ExLlamaV2达到17.36 ms/step。

<h3 id="3">[3] A Reconfigurable Computing In-Memory Macro with Charge-sharing-based Weighted Accumulator</h3>
- **arXiv**: [2605.30814](https://arxiv.org/abs/2605.30814)
- **Authors**: Junyi Yang, Shuai Dong, Zhengnan Fu, Hongyang Shang, Arindam Basu
- **Subjects**: cs.AR
- **Tags**: Compute-in-Memory, Hardware Architecture
- **Summary**: 基于SRAM的模拟存内计算面临ADC开销大、多比特输入延迟高、读位线电压受限等问题。提出一种多比特高可重构256x128存内计算阵列，采用IMADC（面积开销仅3%）、BSCHA（延迟降低1.9x至6.6x）和双8T位单元（线性度提升7x，电压提升3.5x）。支持1-7b输入、2-4b权重、1-7b输出，显著改善性能。

<h3 id="4">[4] HE^2: A Communication-Light Heterogeneous Architecture for Efficient Fully Homomorphic Encryption</h3>
- **arXiv**: [2605.31004](https://arxiv.org/abs/2605.31004)
- **Authors**: Shangyi Shi, Husheng Han, Zhaoxuan Kan, Yinghao Yang, Jianan Mu, Tenghui Hua, Ge Yu, Xinyao Zheng, Ling Liang, Zidong Du, Xing Hu
- **Subjects**: cs.AR; cs.CR
- **Tags**: Homomorphic Encryption, Hardware Accelerator, Heterogeneous Computing
- **Summary**: CKKS全同态加密方案中，密钥切换操作导致频繁的长延迟异构通信，成为性能瓶颈。提出HE^2，一种通信轻量级的xPU-xMU异构FHE加速器，通过数据流图优化和架构协同设计，利用提升算法和组级流水线隐藏通信延迟。相比最优加速器，速度提升1.66倍，EDAP降低9.23倍，通信停顿仅占总延迟6.67%。

<h3 id="5">[5] MixFP4: Enhancing NVFP4 with Adaptive FP4/INT4 Block Representations</h3>
- **arXiv**: [2605.31035](https://arxiv.org/abs/2605.31035)
- **Authors**: Jiaxiang Zou, Yonghao Chen, Ruilong Wu, Xinyu Chen
- **Subjects**: cs.AR
- **Tags**: Quantization, LLM Inference, Model Compression
- **Summary**: NVFP4等低精度格式在块级张量统计上存在单一微格式不匹配问题。提出MixFP4，通过在每块中选择E2M1或E1M2两种FP4微格式，并复用NVFP4的尺度层次，零额外元数据编码格式选择。在代表性LLM上，MixFP4相比NVFP4提升了量化鲁棒性和准确性，仅增加3.1%面积和1.5%功耗。
