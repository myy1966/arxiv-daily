## 新投稿 (4)

<h3 id="1">[1] Constant Depth Threshold Circuits For Exhaustive Epistasis Detection</h3>
- **arXiv**: [2605.29719](https://arxiv.org/abs/2605.29719)
- **Authors**: André Ribeiro, Aleksandar Ilic, Leonel Sousa
- **Subjects**: cs.AR
- **Tags**: Neuromorphic Computing, Hardware Accelerator, Computational Biology, Epistasis Detection
- **Venue**: ICONS '25
- **Summary**: 该论文针对生物信息学中计算复杂的上位性检测问题，提出利用阈值门电路在神经形态硬件上实现高效计算。通过数据编码和组合生成策略，结合恒定深度的阈值门电路进行群体计数，使得运行时间仅受组合数量限制且无额外开销。关键结果是实现了对数线性空间复杂度，并在实际硬件中验证了效率。

<h3 id="2">[2] Design-Oriented Modeling of TSV Substrate Noise Coupling to Ring VCOs</h3>
- **arXiv**: [2605.29867](https://arxiv.org/abs/2605.29867)
- **Authors**: Ilias Exouzidis, Alberto Garcia-Ortiz, George Floros, Georgios Panagopoulos
- **Subjects**: cs.AR
- **Tags**: Hardware Design, Chiplet Design, Circuit Design
- **Venue**: MOCAST 2026
- **Summary**: 该论文研究了三维集成电路中TSV引起的衬底噪声对射频模块的影响，提出了一种紧凑的解析三端口RLGC宏模型。通过22nm FD-SOI工艺的环形VCO设计验证，展示了TSV干扰导致的频谱杂散。结果表明1GHz、0.5Vpp的干扰会引入-35.2dBc的边带杂散，且耦合响应呈低通特性。

<h3 id="3">[3] Precomputed 1D-CNNs for Atrial Fibrillation Detection on Tiny Smart Sensor Systems</h3>
- **arXiv**: [2605.29994](https://arxiv.org/abs/2605.29994)
- **Authors**: Lukas Einhaus, Natalie Maman, Julian Hoever, Andreas Erbslöh, Gregor Schiele
- **Subjects**: cs.AR
- **Tags**: FPGA, Hardware Accelerator, Medical AI, Time Series Analysis
- **Venue**: IEEE SMARTCOMP 2026
- **Summary**: 该论文针对时间序列分析中的1D-CNN在FPGA上部署的扩展性问题，提出基于LUT预计算和分组卷积的优化方法。以心房颤动检测为例，在MIT-BIH心电图数据集上，所实现的硬件加速器仅消耗2844个LUT，无需DSP或BRAM，而F1得分达到95%。

<h3 id="4">[4] elasticAI.explorer: Towards a Unified End-to-End Framework for Hardware-Aware Neural Architecture Search</h3>
- **arXiv**: [2605.30019](https://arxiv.org/abs/2605.30019)
- **Authors**: Natalie Maman, Florian Hettstedt, Andreas Erbslöh, Gregor Schiele
- **Subjects**: cs.AR
- **Tags**: Neural Architecture Search, AutoML
- **Summary**: 该论文提出elasticAI.explorer框架，用于硬件感知的神经架构搜索（NAS）。框架采用YAML描述搜索空间，支持多种搜索空间形式，并集成了硬件代码生成、Docker交叉编译和片上基准测试。通过统一接口降低了嵌入式AI部署的工程开销，加速了异构加速器平台的NAS研究。

<h3 id="5">[5] Rotary GPU: Exploring Local Execution Paths for Large Mixture-of-Experts Models Under Limited GPU Memory</h3>
- **arXiv**: [2605.29135](https://arxiv.org/abs/2605.29135) (cross-listed)
- **Authors**: Myeong Jun Jo
- **Subjects**: cs.PF; cs.AR; cs.DC
- **Tags**: LLM Inference, Mixture-of-Experts, LLM Deployment
- **Summary**: 该论文针对大型混合专家模型在有限GPU内存下的部署问题，提出Rotary GPU方法。在配备8GB VRAM的RTX 4060笔记本GPU上，成功运行Qwen3.6-35B-A3B模型，生成2048个token时VRAM占用约6.3GB，解码吞吐量为21.06 tokens/s。结果表明大型模型在资源受限环境下的部署可行性值得继续探索。

<h3 id="6">[6] Space-Control: Process-Level Isolation for Sharing CXL-based Disaggregated Memory</h3>
- **arXiv**: [2603.06951](https://arxiv.org/abs/2603.06951) (replaced)
- **Authors**: Kaustav Goswami, Sean Peisert, Venkatesh Akella, Jason Lowe-Power
- **Subjects**: cs.AR; cs.CR; eess.SY
- **Tags**: Hardware Security, Memory Architecture, Trusted Execution Environment, Disaggregated Memory
- **Summary**: 该论文针对基于CXL的共享分解内存中缺乏进程级隔离的安全问题，提出Space-Control架构。通过跨主机身份原语和硬件根信任的验证引擎，实现细粒度权限验证。在255个主机上支持127个并发进程，存储开销仅1.56%，性能损失仅3.3%。为安全的进程级内存分解提供了实用基础。
