<h3 id="1">[1] Compiling Semi-Ring Dynamic Programming to Tier-Aware 3D-DRAM Processing-in-Memory</h3>
- **arXiv**: [2610.09156](https://arxiv.org/abs/2610.09156)
- **Authors**: Mahbod Afarin, Tsung-Han Lu, Tajana Rosing
- **Subjects**: cs.AR
- **Tags**: Processing-in-Memory, Compiler Optimization
- **Summary**: 该论文针对3D-DRAM存内计算（PIM）上动态规划（DP）任务需要手写内核、程序员须手动选择分块大小、跨非均匀延迟存储层放置数据并划分异构处理单元工作的问题，提出了MLIR编译器GenMLIR。它将半环广义网格更新这一APSP与序列比对共享的代数形式编码为一等IR抽象，并通过四组GenDRAM感知的编译pass自动完成分块、分层放置、瓦片到PU分配与显式通信。在GenDRAM架构上，生成代码比无编译器支持的lowering快5.8倍（APSP）和16.7倍（比对），比标准仿射分块PIM编译器快1.2-1.4倍，达到可达性能上界的90-100%，且代码量从300-500行降至4-9行。

<h3 id="2">[2] An Interleaved Parallel Dependent Quantization Hardware Architecture for H.266/VVC</h3>
- **arXiv**: [2610.09292](https://arxiv.org/abs/2610.09292)
- **Authors**: Jun Zhang, Weizhi Bian, Hao Zhang
- **Subjects**: cs.AR
- **Tags**: Hardware Architecture, Video Streaming
- **Summary**: H.266/VVC中的依赖量化虽压缩率高，但串行性强、复杂度高，难以满足实时部署需求。本文提出一种交织并行依赖量化硬件架构，通过时分复用大部分组合逻辑实现四通道并行，并采用帧内CG上下文简化方案与在率估计中跳过decAbslevel的编码方案。该设计在All Intra和Random Access配置下BDBR损失仅为0.42%和0.38%；在Xilinx XCZU19 FPGA上实现4K@33.2-454.1 fps，在TSMC 28nm ASIC上达到4K@84.0-1147.7 fps。

<h3 id="7">[7] CXDVirt: Low Latency Kernel Module Based CXL-SSD Emulation</h3>
- **arXiv**: [2610.08899](https://arxiv.org/abs/2610.08899) (cross-listed)
- **Authors**: Hyunsun Chung, Seongho Bong, Hong-Yeon Kim, Youngjae Kim
- **Subjects**: cs.PF; cs.AR; cs.ET
- **Tags**: Storage Systems, Performance Modeling
- **Venue**: 17th International Workshop on Performance Modeling, Benchmarking and Simulation of High Performance Computer Systems (PMBS)
- **Summary**: CXL-SSD通过设备内小容量DRAM缓存提供对NAND级容量的内存语义访问，但硬件稀缺使仿真成为研究核心，而现有最先进仿真器Cylon在VM中运行工作负载并拦截DRAM缺失，其VM机制每次缺失增加超过3μs开销，超过高性能NAND读延迟。本文提出基于内核模块的CXDVirt仿真器，完全去除VM：设备通过主机devdax暴露，命中由MMU原生处理，缺失通过自定义缺页路径建模NAND延迟。CXDVirt保持CXL-SSD双峰延迟特性，将每次缺失延迟降低1.4-1.6倍（P99.9处达4.1倍），八线程下缺失延迟仅翻倍（Cylon因QEMU全局锁为8-9倍），无NAND流量时与远端DRAM差距在5%以内，而Cylon慢3.1-3.6倍。

<h3 id="8">[8] Fault-tolerant foundation models</h3>
- **arXiv**: [2610.10311](https://arxiv.org/abs/2610.10311) (cross-listed)
- **Authors**: Trevor McCourt, Ila R. Fiete, Isaac L. Chuang
- **Subjects**: cs.LG; cs.AI; cs.AR
- **Tags**: Fault Tolerance, Scaling Laws
- **Summary**: 新兴计算机硬件常以可靠性换取能效，本文研究大语言模型能否被训练以容忍这种不可靠性。基于4万GPU小时的模拟故障数字硬件训练实验，作者推导出修正的神经缩放定律，量化了模型越大错误容忍度反而越强的趋势，并表明模型学会在“好”的纠错码内进行计算，其相对开销不随模型规模增长。该发现引出猜想：经过适当训练的LLM可能具有形式化容错性，若成立，则在低能耗、易故障硬件上运行AI推理有望大幅节能。
