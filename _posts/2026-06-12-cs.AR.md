## 新投稿 (3)

<h3 id="1">[1] Non-Parametric Dual-Manifold Mapping via 8-Bit Bounded Transformation Matrices: Challenging FP-centric Hardware Paradigms in Low-Energy AI</h3>
- **arXiv**: [2606.13328](https://arxiv.org/abs/2606.13328)
- **Authors**: Lars Kopp
- **Subjects**: cs.AR
- **Tags**: Neuromorphic Computing, Energy Efficiency
- **Summary**: 该论文针对深度学习硬件中浮点运算的高能耗问题，提出了一种基于8位整数变换的非参数化双流形映射框架，无需训练即可实现低能耗推理。通过使用位运算和累积逻辑，在90%稀疏性和20%节点破坏下仍能近乎完美重建，为神经形态边缘计算提供了新范式。

<h3 id="2">[2] SupraSNN: Exploiting Synapse-Level Parallelism in Spiking Neural Network Accelerators through Co-Optimized Mapping and Scheduling</h3>
- **arXiv**: [2606.13354](https://arxiv.org/abs/2606.13354)
- **Authors**: Seyed Sadra Ghavami, Mohammad Hossein Nikkhah, Mohammad Rasoul Roshanshah, Saeed Safari
- **Subjects**: cs.AR; cs.DC; cs.NE
- **Tags**: Neuromorphic Computing, SNN Training, Hardware Acceleration
- **Summary**: 该论文针对脉冲神经网络硬件实现中功耗高、状态不稳定的问题，提出了SupraSNN，一种超标量启发式架构，通过解耦突触和神经元计算实现高突触级并行性。在FPGA上实现93.44%的MNIST准确率，推理延迟149微秒，能效比现有方案提升5.6倍。

<h3 id="3">[3] ReSCom: A Reconfigurable Spiking Neural Network Accelerator Using Stochastic Computing</h3>
- **arXiv**: [2606.13560](https://arxiv.org/abs/2606.13560)
- **Authors**: Ali Alipour Fereidani, Mohammad Rasoul Roshanshah, Saeed Safari
- **Subjects**: cs.AR; cs.NE
- **Tags**: Neuromorphic Computing, Stochastic Computing, Reconfigurable Computing
- **Summary**: 该论文针对脉冲神经网络硬件实现中功耗高、状态不稳定的问题，提出了ReSCom，一种基于随机计算的可重构SNN加速器，采用统一神经元设计支持多种模型。在MNIST上达到92.80%准确率，每张图像仅消耗0.05 mJ，能效优于现有方案。

## 跨领域投稿 (6)

<h3 id="4">[4] Eidola: Modeling Multi-GPU Network Communication Traffic in Distributed AI Workloads</h3>
- **arXiv**: [2606.12638](https://arxiv.org/abs/2606.12638) (cross-listed)
- **Authors**: Ranganath R. Selagamsetty, Matthew Poremba, Bradford M. Beckmann, Joshua San Miguel, Mikko H. Lipasti
- **Subjects**: cs.DC; cs.AR
- **Tags**: GPU Computing, Distributed Training
- **Summary**: 该论文针对多GPU系统中由于内核融合和通信重叠导致的流量难以建模问题，提出了Eidola，一种可扩展的gem5模拟器扩展，能够周期级精确模拟GPU间通信。实验验证了融合内核执行的可变性，并通过SyncMon减少了轮询相关内存流量。

<h3 id="5">[5] Reducing the Complexity of Deep Learning Models for EEG Analysis on Wearable Devices</h3>

- **Subjects**: cs.AI; cs.AR
- **Tags**: EEG Analysis, Model Compression, Wearable Computing
- **Summary**: 该论文针对深度学习模型在可穿戴设备上部署时的资源限制问题，研究了参数量化和电极减少方法在EEG癫痫检测中的准确率与计算复杂度权衡。结果表明这些技术能显著降低复杂度而准确率损失很小。

<h3 id="6">[6] Quantum-Driven Neuromorphic Computing for Million-Qubit-Scale Workloads</h3>
- **arXiv**: [2606.12968](https://arxiv.org/abs/2606.12968) (cross-listed)

- **Subjects**: cs.AR
- **Tags**: Neuromorphic Computing, Ising Machine
- **Summary**: 该论文针对室温下量子启发计算的需求，提出了Apollo，一种基于p-qubit的神经形态处理器，利用量子熵实现随机转变。在三维自旋玻璃基准上获得了低于低温量子退火硬件的基态能量，支持室温操作。

<h3 id="7">[7] Modern analog computing for solving differential and matrix equations</h3>

- **Authors**: Zhong Sun, Piergiulio Mannocci, Manuel Le Gallo, Abu Sebastian
- **Subjects**: cs.ET; cs.AI; cs.AR; cs.NE

<h3 id="8">[8] Positional Encoding in the Context of Memristor-Based Analog Computation for Automatic Speech Recognition</h3>

- **Authors**: Benedikt Hilmes, Nick Rossenbach, Ralf Schlüter
- **Subjects**: cs.LG; cs.AR; cs.ET
- **Tags**: Analog Computing, Automatic Speech Recognition, Memristor
- **Venue**: Interspeech 2026

- **Authors**: Nikhil Rout, Blaise Tine
