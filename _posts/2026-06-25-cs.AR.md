<h3 id="1">[1] SPORT: Spherical-PSNR-Optimized tRuncaTion for Power-Efficient 360-Degree Video Systems</h3>
- **arXiv**: [2606.24916](https://arxiv.org/abs/2606.24916)
- **Authors**: Md. Sajjad Hossain, Hasibur Rahman Hemel, Kyle Mooney, Yiwen Xu, William Oswald, Mario Renteria-Pinon, Hritom Das, Zhenlin Pei, Jinhui Wang, Na Gong
- **Subjects**: cs.AR; cs.MM
- **Tags**: Virtual Reality, Energy Efficiency, Memory Architecture
- **Summary**: 针对VR头显中内存带宽占功耗30-40%的问题，提出SPORT位截断框架，利用WS-PSNR优化约束和注视预测瓦片分类减少显示路径内存功耗。在SkyWater 130nm ASIC上验证，SPORT-B实现47.9%功耗节省和带宽降低，SPORT-A达到51.6%功耗节省，且满足WS-PSNR阈值。

<h3 id="2">[2] SafeGen: LLM-Driven Assertion Generation and Fault Criticality Evaluation for Functional Safety</h3>
- **arXiv**: [2606.25296](https://arxiv.org/abs/2606.25296)
- **Authors**: Xuanyi Tan, Arjun Chaudhuri, Rubin Parekhji, Krishnendu Chakrabarty
- **Subjects**: cs.AR
- **Tags**: Assertion Generation, RTL Verification, LLM for EDA
- **Venue**: DAC 2026
- **Summary**: 针对传统仿真故障分析过于保守的问题，提出SafeGen框架，利用LLM、超知识图谱和形式化验证生成功能安全断言并评估故障关键性。实验表明SafeGen生成的断言质量优于现有LLM方法，且故障关键性评估具有更高语义可解释性。

<h3 id="3">[3] Cache-Resident LLM Inference in GB-Scale Last-Level Caches</h3>
- **arXiv**: [2606.25353](https://arxiv.org/abs/2606.25353)
- **Authors**: Wanning Zhang, Tongzhou Gu, Marco Canini, Ceyu Xu, Jian Weng
- **Subjects**: cs.AR
- **Tags**: LLM Inference, Cache Management, Memory Architecture
- **Summary**: 针对LLM推理中数据移动瓶颈和缓存驻留权重的同步问题，提出缓存驻留执行模型，解耦权重相关操作与注意力，并放松同步依赖。在多插槽CPU集群上部署Llama-3.2-3B和Llama-2-7B，实现2.04x-11.51x的TPOT加速比，分析模型预测最高13.9x加速。

<h3 id="4">[4] Energy-Efficient CNN Acceleration with MSDF Digit-Serial Arithmetic on FPGA</h3>
- **arXiv**: [2606.25562](https://arxiv.org/abs/2606.25562)
- **Authors**: Muhammad Usman, Yousef Sadegheih, Dorit Merhof
- **Subjects**: cs.AR; cs.CV
- **Tags**: FPGA, Energy Efficiency, Edge Computing
- **Venue**: 2025 32nd IEEE International Conference on Electronics, Circuits and Systems (ICECS)
- **Summary**: 针对数字串行运算中初始延迟累积问题，提出合并乘加（MMA）架构，将乘法和加法融合为统一流水线。在FPGA上实现U-Net加速，能效达15.14 GOPS/W，相比CPU提高约一个数量级，相较MSDF实现降低约9倍能耗。
