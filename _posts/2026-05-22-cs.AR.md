## 新投稿 (3)

<h3 id="1">[1] CompPow: A Case for Component-level GPU Power Management</h3>
- **arXiv**: [2605.21847](https://arxiv.org/abs/2605.21847)
- **Authors**: Shaizeen Aga, Mohamed Assem Ibrahim
- **Subjects**: cs.AR; cs.DC
- **Tags**: GPU Computing, Power Management, Energy Efficiency
- **Summary**: 本文提出CompPow，一种面向现代GPU的组件级功耗管理方案，通过感知GPU内部集成组件的功耗特性来实现更优的功耗管理。实验表明，该方法可在多种ML操作中实现10%的能效提升和5%的性能提升。

<h3 id="2">[2] Emerging memory technologies at room/cryogenic temperature</h3>
- **arXiv**: [2605.21912](https://arxiv.org/abs/2605.21912)
- **Authors**: Siddhartha Raman Sundara Raman
- **Subjects**: cs.AR
- **Tags**: Memory Architecture, Quantum Computing
- **Summary**: 本文综述了室温与低温环境下工作的各类易失性和非易失性存储技术，包括SRAM、DRAM、RRAM、MRAM、FeFET存储器以及面向量子计算平台的低温存储技术。文章分析了这些存储技术的操作原理、读写机制、保持特性以及在面积、性能、可扩展性和能效方面的权衡。

<h3 id="3">[3] NasZip: Software and Hardware Co-Design to Accelerate Approximate Nearest Neighbor Search with DIMM-Based Near-Data Processing</h3>
- **arXiv**: [2605.21952](https://arxiv.org/abs/2605.21952)
- **Authors**: Cheng Zou, Shuo Yang, Chen Nie, Yu Zou, Yu He, Chao Jiang, Limin Xiao, Weifeng Zhang, Zhezhi He
- **Subjects**: cs.AR; cs.DB; cs.DC
- **Tags**: Approximate Nearest Neighbor, RAG, Near-Data Processing, Hardware-Software Co-design
- **Venue**: ISCA 2026
- **Summary**: 本文提出NASZIP，一种软硬件协同设计的框架，通过近数据处理(NDP)和基于PCA的特征级早退机制加速RAG系统中的近似最近邻搜索(ANNS)。该框架相比CPU基线和最先进GPU实现分别实现高达8.4倍和1.4倍的加速，相比最先进NDP ANNS加速器实现1.69倍性能提升。

## 跨领域投稿 (1)

<h3 id="4">[4] ORBIS: Output-Guided Token Reduction with Distribution-Aware Matching for Video Diffusion Acceleration</h3>
- **arXiv**: [2605.22015](https://arxiv.org/abs/2605.22015) (cross-listed)
- **Authors**: Hangyeol Lee, Joo-Young Kim
- **Subjects**: cs.CV; cs.AR
- **Tags**: Diffusion Model, Hardware Acceleration, Token Compression, Video Generation
- **Summary**: 本文提出ORBIS，一种面向视频扩散Transformer的软硬件协同设计加速器，利用前一时间步的输出激活获取更准确的token相似度，并引入分布感知token匹配算法。该方法实现了比现有方法高2倍的token压缩率，相比NVIDIA A100 GPU实现高达4.5倍加速和79.3%的能耗降低。

<h3 id="5">[5] FASE: FPGA-Assisted Syscall Emulation for Rapid End-to-End Processor Performance Validation</h3>
- **arXiv**: [2509.08405](https://arxiv.org/abs/2509.08405) (replaced)
- **Authors**: Chengzhen Meng, Xiuzhuang Chen, Bingcai Sui, Zhenyu Zhao, Tun Li, Hongjun Dai
- **Subjects**: cs.AR
- **Tags**: FPGA, Hardware Verification, RISC-V
- **Venue**: IEEE TCAD
- **Summary**: 本文提出FASE框架，首个在FPGA平台上实现系统调用模拟的工作，使复杂多线程基准测试能够直接在处理器设计上运行，无需集成SoC或目标操作系统即可进行早期性能验证。实验表明，FASE对单线程工作负载实现超过96%的性能验证准确率，相比Proxy Kernel实现超过2000倍的效率提升。

<h3 id="6">[6] Spec2Cov: An Agentic Framework for Code Coverage Closure of Digital Hardware Designs</h3>
- **arXiv**: [2604.15606](https://arxiv.org/abs/2604.15606) (replaced)
- **Authors**: Sean Lowe, Elias Hilaneh, Alma Babbit, Nakul Gopalan, Vidya Chhabria, Aman Arora
- **Subjects**: cs.AR
- **Tags**: RTL Verification, LLM Agent
- **Summary**: 本文提出Spec2Cov，一个基于LLM的智能体框架，能够从设计规范自动迭代生成测试激励以加速硬件验证的覆盖率收敛。该框架协调LLM与硬件仿真器的交互，在26个设计中实现了简单设计100%覆盖率和复杂设计高达49%的覆盖率。
