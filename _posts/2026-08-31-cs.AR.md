## 新投稿 (3)

<h3 id="1">[1] AI Hardware Accelerators for Large Language Models: Architectures and the Memory Wall</h3>
- **arXiv**: [2608.28048](https://arxiv.org/abs/2608.28048)
- **Authors**: Siddharth Patel, Rohit Singh
- **Subjects**: cs.AR; cs.DC
- **Tags**: AI Accelerator, Memory Architecture, LLM Inference
- **Summary**: 该综述指出大规模语言模型对硬件的需求受制于内存墙，而非计算能力，解码阶段带宽受限，KV缓存和能耗成为关键。文章梳理了从GPU、ASIC、FPGA到存内计算、神经形态和光子计算等各类加速器，并用roofline分析比较。结果发现无单一架构最优，存内计算是近期最有前景的应对方案，未来需依赖软硬件协同设计及内存中心系统。

<h3 id="2">[2] Gen-TAS: A Generative AI-Aided Hardware-Software Task Allocation Framework for FPGA-GPP Heterogeneous Systems</h3>
- **arXiv**: [2608.28160](https://arxiv.org/abs/2608.28160)
- **Authors**: Mary Kong, Yuqin Zhao, Semih Vazgecen, Cristian Sestito, Themis Prodromakis
- **Subjects**: cs.AR; cs.AI; cs.HC
- **Tags**: Hardware-Software Co-design, Task Allocation, RAG
- **Summary**: 针对FPGA-GPP异构系统任务分配依赖专家经验且目标多样的问题，提出Gen-TAS，一种知识增强的LLM任务分配框架，结合任务图分析和RAG，生成可解释的分配策略，并通过人在环和确定性后端实现部署。在CNN和SDR负载上，延迟目标下相比全GPP基线实现最高2.45倍和92.53倍加速。

<h3 id="3">[3] Neuromorphic architectures as numerical solvers for computational neuroscience</h3>
- **arXiv**: [2608.28387](https://arxiv.org/abs/2608.28387)
- **Authors**: Jakob Jordan, Ole Richter, Congyang Li, Mihai A. Petrovici, Rajit Manohar
- **Subjects**: cs.AR; q-bio.QM
- **Tags**: Neuromorphic Computing, Computational Neuroscience
- **Summary**: 现有神经形态硬件主要为脉冲神经元设计，不适合连续耦合的率模型，本文将其分布式模拟视为消息传递算法，提出多比特包通信和更高阶数值求解器的设计原则。将现有神经形态架构转换为无脉冲分布式数值求解器，在降低能耗和延迟的同时获得更低的数值误差。

<h3 id="4">[4] Great Expectations: Benchmarking the Real-World Performance of RVV 1.0 in HPC</h3>
- **arXiv**: [2608.28097](https://arxiv.org/abs/2608.28097) (cross-listed)
- **Authors**: Stepan Nassyr, Prateek Chawla, Daniel Seibel, Jayesh Badwaik, Kaveh Haghighi Mood, Andreas Herten
- **Subjects**: cs.DC; cs.AR; cs.ET
- **Tags**: RISC-V, Vector Processor, High Performance Computing
- **Venue**: International workshop on RISC-V for HPC at ISC26
- **Summary**: 为评估RISC-V向量扩展RVV 1.0在HPC环境的实际性能，对SiFive X280、SpacemiT X60、T-Head C920v2等最新硬件运行BLAS、FFTW、HPL、HPCG等标准基准并与NVIDIA Grace对比。结果显示RVV相比标量执行有显著性能提升，但硬件实现存在挑战，并指出走向HPC主流的剩余障碍。

<h3 id="5">[5] Beyond Flat Netlist: Hierarchical Graph Representation Learning for Scalable Analysis of Sequential Circuits</h3>
- **arXiv**: [2608.28188](https://arxiv.org/abs/2608.28188) (cross-listed)
- **Authors**: Jingyi Zhou, Zhengyuan Shi, Jiaying Zhu, Ziyang Zheng, Qiang Xu
- **Subjects**: cs.LG; cs.AI; cs.AR
- **Tags**: Graph Neural Network, EDA, Circuit Representation Learning
- **Summary**: 针对电路表示学习在工业级规模下可扩展性差且缺乏时序动态建模的问题，提出DeepSeq3层次化框架，将电路抽象为组合子图和超节点图，使用双GNN学习局部逻辑与全局状态转移，并通过状态中心预训练预测状态可达性。在大规模基准上将BMC求解时间降低18%，同时保证正确性。

- **arXiv**: [2608.26418](https://arxiv.org/abs/2608.26418) (replaced)
- **Authors**: Architect Labs
- **Subjects**: cs.AR; cs.AI
- **Tags**: AI Accelerator, RTL Generation, Hardware-Software Co-design
- **Summary**: 针对AI硬件设计周期远慢于工作负载演化的问题，提出一个端到端AI系统，将软硬件协同设计与验证整合为单一优化循环，自主生成性能模型、RTL、UVM环境、形式证明、固件和内核。Redwood在2周内完成设计和部署，相比Jetson Orin Nano在相同模型上实现3.4倍性能功耗比提升。
