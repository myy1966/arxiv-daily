<h3 id="1">[1] AI-Driven Thermal Mapping and Management in 3D Integrated Photonic Circuits</h3>
- **arXiv**: [2607.07711](https://arxiv.org/abs/2607.07711)
- **Authors**: Liton Kumar Biswas, Katayoon Yahyaei, Shajib Ghosh, M Shafkat M Khan, Himanandhan Reddy Kottur, Rayhane Ghane-Motlagh, Mahdi Nikdast, Navid Asadizanjani
- **Subjects**: cs.AR; eess.IV
- **Tags**: Thermal Management, 3D Integration, Photonic Computing
- **Venue**: IMAPSource Proceedings 2025
- **Summary**: 针对三维光子集成电路（3D PIC）中热管理难题，提出结合AI热建模框架与启发式方法的双方案。AI模型融合稀疏传感器数据与设计信息预测温度分布，启发式方法利用局部材料特性细化估计。该方法实现可扩展的实时热映射，支撑下一代3D光子系统的可靠热管理。

<h3 id="2">[2] A Theoretical Framework for Stochastic Activity Prediction in Tensor Accelerator Wallace-Tree Multipliers</h3>
- **arXiv**: [2607.08002](https://arxiv.org/abs/2607.08002)
- **Authors**: Prashanthi Metku, Chandra Gandu
- **Subjects**: cs.AR; cs.ET
- **Tags**: Hardware Acceleration, Energy Efficiency, Low Power
- **Summary**: 针对张量加速器乘法器在稀疏操作数时仍消耗动态功率的问题，提出随机活动预测（SAP）方法。该方法通过预测操作数汉明重量来提前冻结输入，并给出三个形式化定理保证预测误差。SAP填补了现有功率优化技术的空白，在不产生错误结果的前提下实现节能。

<h3 id="3">[3] CRIMP: Compact & Reliable DNN Inference on In-Memory Processing via Crossbar-Aligned Compression and Non-ideality Adaptation</h3>
- **arXiv**: [2607.08015](https://arxiv.org/abs/2607.08015)
- **Authors**: Shuo Huai, Hao Kong, Xiangzhong Luo, Shiqing Li, Ravi Subramaniam, Christian Makaya, Qian Lin, Weichen Liu
- **Subjects**: cs.AR
- **Tags**: Processing-in-Memory, Model Compression, Hardware Accelerator
- **Venue**: ACM Transactions on Embedded Computing Systems
- **Summary**: 针对存内处理（IMP）加速器面临的浮点不兼容、冗余参数和非理想行为三大问题，提出CRIMP框架。通过重用移位单元实现整数仅量化、核分组与交叉开关剪枝去除对齐单元、运行时感知非理想性适应，在单一训练过程中解决所有问题。在CIFAR-10上，VGG-16和ResNet-56精度损失仅2.19%和1.26%。

<h3 id="4">[4] Who Needs DRAM? We Have Fiber</h3>
- **arXiv**: [2607.08407](https://arxiv.org/abs/2607.08407)
- **Authors**: Hannah Atmer, Thiemo Voigt, Yuan Yao, Stefanos Kaxiras
- **Subjects**: cs.AR; cs.DC; cs.ET; cs.NI
- **Tags**: Memory Architecture, LLM Inference, Optical Memory
- **Summary**: 针对DRAM供应紧张和AI大内存需求，提出光纤内存（Fiber Memory）架构，将光纤用作循环延迟线内存存储不可变数据（如LLM权重）。通过空分复用多芯光纤、无源光耦合等实现数据并行广播。评估显示，在10000个AI加速器上可消除冗余权重存储，权重传输能耗较HBM3e降低70%以上。

<h3 id="5">[5] FPGN: Redefining Ultra-Fast Programmable Gate-based Neural Acceleration with Differentiable LUTs</h3>
- **arXiv**: [2607.08427](https://arxiv.org/abs/2607.08427)
- **Authors**: Jiawei Liang, Haotong Qin, Linfeng Du, Xingyu Liu, Shangkun Li, Hui Yu, Michele Magno, Xinyu Chen, Jiang Xu, Wei Zhang
- **Subjects**: cs.AR; cs.LG
- **Tags**: FPGA, Hardware Accelerator, LUT-based Neural Network
- **Summary**: 针对LUT原生神经网络在FPGA上实现延迟优化的差距，提出FPGN端到端物理感知框架。包括硬件对齐的可微LUT公式、结构化LUT拓扑和流式架构、延迟驱动编译器。实验表明，相较于传统FPGA BNN加速器延迟降低205倍，LUT效率提升30倍，同时保持竞争力精度。

<h3 id="6">[6] Detecting Ladder Logic Bombs in IEC 61131-3 PLC Programs using ESBMC-PLC+: A Formal Verification Approach with Trigger Synthesis</h3>
- **arXiv**: [2607.08417](https://arxiv.org/abs/2607.08417) (cross-listed)
- **Authors**: Pierre Dantas, Lucas Cordeiro, Waldir Junior
- **Subjects**: cs.CL; cs.AR
- **Tags**: Formal Verification, Program Verification, Cybersecurity
- **Summary**: 针对PLC程序中隐藏的阶梯逻辑炸弹（LLB）检测问题，提出ESBMC-LLB方法。通过建模层暴露功能块逻辑，将炸弹检测转化为形式验证问题，并使用k-归纳法证明无炸弹。在Iacobelli 2024数据集上检测出全部30个炸弹，在SWaT语料库上实现149/150检测率、零误报。

- **Authors**: Pierre Dantas, Lucas Cordeiro, Waldir Junior
- **Subjects**: cs.PL; cs.AR; eess.SY
- **Tags**: Formal Verification, Program Verification, Cyber-Physical Systems
- **Summary**: 针对开放硬件PLC形式验证的部署差距（如16位字长和有限ADC导致误报），提出硬件忠实验证方法。通过声明式硬件抽象层描述和合理降级解释，在ESBMC中实现输入范围模型。在123个程序语料库上消除所有54个误报，并检测到宽度相关的真正缺陷。

<h3 id="8">[8] SPEC CPU2026: Characterization, Representativeness, and Cross-Suite Comparison</h3>
- **arXiv**: [2605.03713](https://arxiv.org/abs/2605.03713) (replaced)
- **Authors**: Ruihao Li, Andrew Jacob, Neeraja J. Yadwadkar, Lizy K. John
- **Subjects**: cs.AR; cs.PF
- **Tags**: CPU Benchmark, Performance Evaluation
- **Summary**: 该论文针对SPEC CPU2026基准测试套件是否改变以往CPU架构结论的问题，对套件进行了全面特征描述和跨套件比较。通过聚类分析识别出每组4-5个负载的紧凑子集，可保留96.4-99.9%的全套行为。结果显示SPEC CPU2026增加了指令体积和内存占用，前端压力增大，且与SPEC CPU2017、DCPerf、MLPerf等套件互补，为未来十年CPU架构评估提供了更新后的标准化基准。
